# ลิขสิทธิ์ของภาพ คลิป มีม และเสียงที่แทรก

kit นี้ไม่มีคลังมีมหรือคลังภาพแถมมาให้ ของที่แทรกลงคลิปมาจาก 2 ทาง คือไฟล์ของคุณเอง กับของที่ Claude หาจากเน็ตตามที่คุณสั่ง ทุกชิ้นถูกจดไว้ในไฟล์ `CREDITS.md` ในโฟลเดอร์งานของคลิปนั้น พร้อมช่อง "ใช้ยิงแอดได้" ใช่หรือไม่

## Claude หาจากที่ไหนก่อน
1. แหล่งที่ใช้ฟรีได้จริง: Pexels, Pixabay, Wikimedia Commons (เฉพาะ CC0 หรือ CC BY ซึ่งต้องใส่เครดิต)
2. หน้าทางการของแบรนด์หรือข่าว ใช้แบบอ้างอิงประกอบเรื่องที่เล่า พร้อมป้ายแหล่งที่มาบนจอ
3. คลิปจาก YouTube และมีม ใช้เมื่อคุณอนุญาต

ถ้าคุณเลือกโหมด "ถามก่อน" Claude จะเสนอรายการ (ลิงก์ ใช้ตรงไหน ไลเซนส์อะไร) ให้เลือกก่อนดาวน์โหลดทุกครั้ง

## โพสต์ปกติ กับ ยิงแอด ต่างกัน
- คลิปหนัง ทีวี ภาพข่าว มีมจากรายการต่างๆ ยังเป็นลิขสิทธิ์ของเจ้าของ การเอามาประกอบคลิปเล่าเรื่องแบบมีเครดิตเป็นเรื่องที่ครีเอเตอร์ทำกันทั่วไป แต่ก็ยังมีโอกาสโดนแจ้งลบหรือปิดเสียง
- ถ้าจะจ่ายเงินโปรโมตคลิปนั้น ให้เปลี่ยนทุกชิ้นที่ CREDITS.md บอกว่า "ใช้ยิงแอดได้: ไม่" ก่อน แพลตฟอร์มตรวจโฆษณาเข้มกว่าโพสต์ปกติ
- ภาพจาก Pexels และ Pixabay ใช้ยิงแอดได้ ภาพ CC BY ต้องใส่ชื่อเจ้าของตามที่ CREDITS.md บอก

## ตัวเลขและคำพูดบนจอ
- ทุกตัวเลขที่ขึ้นจอต้องมีแหล่ง (ชื่อแหล่ง + ปี) Claude จะตรวจข้อเท็จจริงให้ก่อนวางการ์ด
- คำพูดของคนอื่นต้องเป็นคำพูดจริงและบอกว่าใครพูด
- ภาพที่สร้างขึ้นมาประกอบ (ไม่ใช่ภาพจริง) ต้องติดป้าย "ภาพจำลอง"

## เพลง
kit ไม่ใส่เพลงประกอบให้เอง ถ้าจะใส่เพลง แนะนำให้ใส่จากคลังเพลงของแอปตอนโพสต์ (TikTok / Instagram) ซึ่งแอปจัดการลิขสิทธิ์ให้
