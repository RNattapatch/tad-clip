# สี ฟอนต์ ตำแหน่งซับ และความละเอียด

ทุกอย่างในหน้านี้เปลี่ยนได้ด้วยการพิมพ์บอก Claude ไม่ต้องเปิดไฟล์เอง
ค่าที่เปลี่ยนใช้กับคลิปถัดไป ถ้าอยากให้คลิปที่ทำเสร็จแล้วเปลี่ยนตาม พิมพ์ `เรนเดอร์คลิปนี้ใหม่ด้วยค่าใหม่` Claude ทำเฉพาะขั้นที่เกี่ยว

## พิมพ์บอก Claude ได้เลย

| อยากได้ | พิมพ์ประมาณนี้ |
|---|---|
| เปลี่ยนสีแบรนด์ | `เปลี่ยนสีแบรนด์เป็น #0f766e` หรือส่งโลโก้แล้วพิมพ์ `เลือกสีจากโลโก้นี้ให้หน่อย` |
| ใช้ชุดสีสำเร็จ | `ใช้ชุดสี paper` |
| ซับใหญ่ขึ้น | `ซับใหญ่ขึ้นอีกนิด` |
| ซับสูงขึ้น หลบปุ่มของแอป | `ดันซับขึ้นอีก` |
| สีคำที่กำลังพูด | `สีไฮไลต์ซับเป็นเหลือง` |
| บรรทัดซับสั้นลง | `ซับบรรทัดละไม่เกิน 18 ตัวอักษร` |
| ชื่อบนการ์ด | `เปลี่ยนชื่อในคลิปเป็น สมชาย ใจดี @somchai.sales` |
| ไฟล์คมขึ้น | `ขอไฟล์ 2K 60fps` |
| ถอดเสียงไม่ไหวจริงๆ (ทางสุดท้าย ไทยพลาดมาก) | `เปลี่ยนโมเดลถอดเสียงเป็น medium` |
| คำที่ถอดผิดประจำ | `จำไว้ว่า ช้อปปี้ ต้องเขียนว่า Shopee` |
| คลังมีม | `ตั้งโฟลเดอร์คลังมีมเป็น <path เต็ม>` |

## ชุดสีสำเร็จ

| ชื่อ | หน้าตา | สีหลัก | สีเน้น | สีรอง |
|---|---|---|---|---|
| `neutral` (ค่าเริ่มต้น) | เรียบ เข้ม ส้มสด | `#111827` | `#f97316` | `#facc15` |
| `paper` | พื้นกระดาษ อ่านง่าย แนว explainer | `#2b2b2b` | `#e4572e` | `#f2c14e` |
| `pun-navy-coral` | สไตล์ @pun_nattapatch กรมท่ากับชมพูแดง | `#072b4e` | `#dd4155` | `#f0b429` |

บอกสีเองได้ทีละสี สีที่ไม่ได้บอกใช้จากชุดสีที่เลือกอยู่

| ชื่อสี | ใช้ตรงไหน |
|---|---|
| `primary` | พื้นการ์ดสีเข้ม และตัวหนังสือบนการ์ดพื้นอ่อน |
| `primary_deep` | เฉดที่เข้มที่สุด ใช้กับตัวหนังสือบนป้ายสีรอง |
| `primary_mid` | เฉดกลางของสีหลัก |
| `accent` | สีเน้น กล่องคำสำคัญ คำที่ขึ้นสี |
| `accent2` | สีรอง ตัวเลขใหญ่ ลูกศร แถบไฮไลต์ |
| `paper` | พื้นการ์ดสีอ่อน |
| `ink` | ตัวหนังสือบนพื้นอ่อน |

สีที่บอกเองชนะชุดสีเสมอ ถ้าภายหลังอยากกลับไปใช้ชุดสีสำเร็จ บอก Claude ว่า `ลบสีที่ตั้งเอง แล้วใช้ชุดสี neutral`

## ซับ

ซับคาราโอเกะใช้ฟอนต์ Prompt ที่มากับ kit คำที่พูดไปแล้วเปลี่ยนเป็นสีไฮไลต์ สีไฮไลต์ซับแยกจากสีแบรนด์ของการ์ด

| ค่า | ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `subtitle.size` | ขนาดตัวอักษร | 60 |
| `subtitle.margin_v` | ระยะจากขอบล่าง ยิ่งมากซับยิ่งสูง ใช้ดันซับพ้นปุ่มของแอป | 340 |
| `subtitle.highlight` | สีคำที่พูดไปแล้ว แบบ `#RRGGBB` | `#FF7F50` |
| `subtitle.max_chars` | ตัวอักษรสูงสุดต่อบรรทัด | 22 |

ขนาด ระยะ และสี มีผลตอนสร้างไฟล์ซับรอบสุดท้ายแล้วฝังใหม่ ไม่ต้องถอดเสียงใหม่
เปลี่ยน `max_chars` ระบบตัดบรรทัดซับใหม่ทั้งคลิปโดยไม่ถอดเสียงซ้ำ เลขบรรทัดซับจึงเปลี่ยน
ช็อตที่แบ่งครึ่งจอ ซับย้ายลงไปใต้รอยต่อเองเพื่อไม่ให้ทับหน้า

## ฟอนต์

kit มากับฟอนต์ Prompt 4 น้ำหนัก (Regular, Medium, SemiBold, Bold) ไลเซนส์ OFL ใช้ได้ทั้งการ์ดและซับ ไม่ต้องลงฟอนต์ในเครื่อง
อยากใช้ฟอนต์อื่น ต้องเอาไฟล์ฟอนต์ไปวางในโฟลเดอร์ `assets/fonts` ของ kit โดยตั้งชื่อไฟล์แบบ `ชื่อฟอนต์-Regular.ttf` `ชื่อฟอนต์-Bold.ttf` แล้วตั้ง `brand.font` เป็นชื่อฟอนต์นั้น บอก Claude พร้อมส่งไฟล์ `.ttf` ให้ Claude ทำได้
โฟลเดอร์นั้นอยู่ในตัว plugin การอัปเดตอาจแทนที่ทั้งโฟลเดอร์ หลังอัปเดตให้เช็คว่าฟอนต์ยังอยู่ ถ้าซับขึ้นเป็นสี่เหลี่ยม แปลว่าหาฟอนต์ไม่เจอ
ใช้ฟอนต์ที่ไลเซนส์อนุญาตให้ใช้งานเชิงพาณิชย์ เช่นฟอนต์ไทยบน Google Fonts

## ความละเอียดไฟล์

| ค่า | ได้อะไร | เหมาะกับ |
|---|---|---|
| `1080p` (ค่าเริ่มต้น) | 1080×1920 ไม่เกิน 30 fps | ลงมือถือทั่วไป เรนเดอร์เร็ว ไฟล์เล็ก |
| `2k60` | 1440×2560 60 fps | อยากได้ภาพคมและลื่น เรนเดอร์นานขึ้นราว 2–3 เท่า ไฟล์ราว 50–100 MB ต่อคลิป 1 นาที |

ค่านี้ใช้ตอนเรนเดอร์แบบมีภาพประกอบ คลิปดิบ 60 fps จากมือถือที่ตั้ง `1080p` จะออกมา 30 fps
ถ้าเลือกแค่ "ตัด + ซับ" หรือ "แค่ซับ" ไฟล์ที่ได้คงความละเอียดและ fps ของคลิปดิบไว้

## โมเดลถอดเสียง

| ค่า | ขนาด | เหมาะกับ |
|---|---|---|
| `large-v3` (ค่าเริ่มต้น) | 3.1 GB | แม่นที่สุดกับภาษาไทย ใช้กับทุกเครื่อง แม้ RAM น้อย (ใช้ RAM ราว 3 GB) |
| `medium` | 1.5 GB | ทางสุดท้ายเมื่อเครื่องรัน large-v3 ไม่ไหวจริงๆ ฟังภาษาไทยพลาดมาก และพลาดไม่เท่ากันในแต่ละเครื่อง |

เปลี่ยนโมเดล Claude จะรันตัวติดตั้งซ้ำเพื่อโหลดโมเดลใหม่ ถามคุณก่อนเพราะต้องโหลดเกิน 1 GB

## คลังคำ (glossary)

คำที่ตัวถอดเสียงฟังผิดประจำ เช่นชื่อร้านหรือชื่อสินค้า ใส่ไว้ครั้งเดียวใช้ได้ทุกคลิป

| ส่วน | ทำอะไร | ตัวอย่าง |
|---|---|---|
| `fixes` | คู่คำ ถอดผิด → ที่ถูก แทนที่อัตโนมัติหลังถอดเสียง | `["ช้อปปี้", "Shopee"]` |
| `protect` | คำที่ Claude ห้ามแก้ตอนตรวจซับ | `"ชาไทยใจดี"` |
| `glue` | คำที่ห้ามตัดแยกบรรทัด | `"ชาไทยใจดี"` |
| `prompt_hint` | คำที่บอกตัวถอดเสียงไว้ล่วงหน้า คั่นด้วย `, ` · ใช้บน Mac และกับโมเดล large-v3 · บน Windows ที่ใช้โมเดลเล็กกว่านั้นจะไม่ถูกส่ง ให้แก้คำที่ฟังผิดด้วย `fixes` แทน | `"ชาไทยใจดี, Shopee, Lazada"` |

ยังไม่รู้ว่าตัวถอดเสียงจะฟังผิดเป็นคำว่าอะไร ใส่แค่ `protect` กับ `prompt_hint` ไปก่อน ตัดคลิปแรกแล้วเห็นคำผิดจริงค่อยเพิ่ม `fixes`

## แก้ไฟล์ตั้งค่าเอง

สำหรับคนที่อยากเปิดไฟล์เอง ไฟล์อยู่ที่

- Mac: `~/.tad-clip/config.json`
- Windows: `%USERPROFILE%\.tad-clip\config.json`

ตัวอย่างไฟล์ที่ตั้งค่าครบ

```json
{
  "speaker": { "name": "สมชาย ใจดี", "handle": "@somchai.sales" },
  "brand": { "preset": "paper", "font": "Prompt", "colors": { "accent": "#0f766e" } },
  "subtitle": { "highlight": "#FF7F50", "size": 60, "margin_v": 340, "max_chars": 22 },
  "output": { "preset": "1080p" },
  "whisper": { "model": "large-v3" },
  "library_dir": "/Users/somchai/Movies/meme",
  "glossary": {
    "fixes": [["ช้อปปี้", "Shopee"]],
    "protect": ["ชาไทยใจดี", "Shopee"],
    "glue": ["ชาไทยใจดี"],
    "prompt_hint": "ชาไทยใจดี, Shopee, Lazada, TikTok Shop"
  },
  "cutout": { "engine": "auto" }
}
```

ไฟล์จริงของคุณจะมีส่วน `tools` และ `whisper` ที่ตัวติดตั้งเขียนไว้ ห้ามลบ `tools` คือที่อยู่ของโปรแกรมที่ kit ใช้ ส่วน `whisper` บอกว่าโหลดโมเดลตัวไหนไว้
`library_dir` บน Windows ใช้ `/` คั่นได้ เช่น `C:/Users/somchai/Videos/meme`
`cutout.engine` มี 4 ค่า: `auto` (Mac ใช้ Apple Vision · Windows ใช้ตัวเสริมถ้าลงไว้) · `vision` · `tb` (ตัวเสริม transparent-background) · `off` (ช็อตตัดพื้นหลังเปลี่ยนเป็นแบ่งครึ่งจอ)
ถ้าไฟล์พังจนอ่านไม่ได้ ตัวติดตั้งจะเก็บไฟล์เดิมไว้เป็น `config.json.broken-<วันเวลา>` แล้วเริ่มจากค่าเริ่มต้น ค่าเดิมยังอยู่ในไฟล์นั้น บอก Claude ให้ย้ายกลับมาได้
