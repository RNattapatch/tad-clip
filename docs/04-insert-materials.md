# แทรกภาพ คลิป มีม และเสียง

kit นี้ไม่มีคลังมีมหรือคลังภาพแถมมาให้ เพราะไม่มีสิทธิ์แจกต่อ
ของที่แทรกลงคลิปมาจาก 2 ทาง: ไฟล์ของคุณเอง กับของที่ Claude หาจากเน็ตตามที่คุณอนุญาต ทุกชิ้นถูกจดลง `CREDITS.md` ในโฟลเดอร์งานของคลิปนั้น

## คำถามที่ Claude ถาม

ตอนเริ่มตัดคลิปแบบ "ครบ" Claude ถาม 3 ข้อ (ถ้าเรียกหาภาพแยกทีหลัง ถาม 2 ข้อแรก)

1. ใส่อะไรบ้าง เลือกได้หลายข้อ: ภาพจริง/หลักฐาน · คลิปจริง · มีม · เสียงเอฟเฟกต์
2. เอามาจากไหน: ให้ Claude หาจากเน็ตให้ · ผมมีไฟล์เอง (บอกโฟลเดอร์) · ผสมกัน
3. แบบภาพประกอบ: cutaway (ตัดไปภาพแล้วกลับมาที่คุณ) หรือ stage (คุณยืนบนเวที ฉากหลังเปลี่ยน) — ต่างกันยังไงดูที่ [2 แบบภาพประกอบ](09-modes.md)

การ์ดข้อความกับกราฟิก Claude วาดในเครื่องให้เสมอ ไม่ต้องเลือก
เลือก "ผสมกัน" Claude ใช้ของที่คุณมีก่อน ส่วนที่ขาดค่อยหาจากเน็ต

## ใช้ไฟล์ของคุณเอง

บอก path เต็มของโฟลเดอร์ เช่น `/Users/somchai/Movies/ของแทรก` หรือ `C:/Users/somchai/Videos/ของแทรก`
ก๊อป path ได้ง่ายๆ: Mac คลิกโฟลเดอร์ใน Finder แล้วกด Option+Cmd+C · Windows คลิกขวาที่โฟลเดอร์ → Copy as path

Claude ก๊อปไฟล์ที่เลือกเข้าโฟลเดอร์งานของคลิป (`assets/proof` `assets/footage` `assets/memes` `assets/sfx` `assets/logo`) ไฟล์ต้นทางของคุณอยู่ที่เดิม ไม่ถูกแก้
ภาพหรือคลิปที่คุณถ่ายเอง จดใน `CREDITS.md` ว่า "ถ่ายเอง" และใช้ยิงแอดได้

## ให้ Claude หาจากเน็ต

Claude ไล่หาตามลำดับนี้ เจอของที่ใช้ได้ในแหล่งแรกแล้วไม่ลงไปแหล่งถัดไป

| ลำดับ | แหล่ง | ใช้ยังไง |
|---|---|---|
| ก | Pexels · Pixabay · Wikimedia Commons (เฉพาะ CC0, public domain, CC BY) | ใช้ได้ฟรี ภาพ CC BY ต้องใส่ชื่อเจ้าของ |
| ข | หน้าทางการของแบรนด์ ข่าวประชาสัมพันธ์ รายงานประจำปี ข่าว | ใช้อ้างอิงเรื่องที่เล่า มีป้าย "ชื่อแหล่ง + ปี" บนจอ |
| ค | คลิป YouTube และคลิปมีม | ใช้เมื่อแหล่ง ก กับ ข ไม่มีของที่เล่าเรื่องนั้นได้ และต้องได้รับอนุญาตจากคุณก่อน |

โหมด "ถามก่อน" Claude ส่งตารางให้เลือกก่อนโหลดทุกครั้ง: อะไร · ลิงก์ · ใช้ตรงไหนของคลิป · ไลเซนส์ · ใช้ยิงแอดได้ไหม · ขนาดหรือความยาว ตอบเป็นเลขข้อที่เอาได้เลย
พิมพ์ว่า `หาให้เลยไม่ต้องถาม` Claude จะข้ามการเสนอรายการเฉพาะรอบนี้ และโหลดจากแหล่ง ก กับ ข เท่านั้น แหล่ง ค ยังต้องถามเสมอ เว้นแต่คุณบอกเองว่าเอาคลิป YouTube หรือมีมจากเน็ตได้ไม่ต้องถาม

กติกาที่ Claude ทำตามทุกครั้ง

- เปิดดูหน้าจริงก่อนเสนอลิงก์ หาไลเซนส์ไม่เจอถือว่า "ใช้ยิงแอดไม่ได้"
- เจอหน้าที่ต้องล็อกอินหรือติดระบบกันบอท จะหยุดแล้วบอกคุณให้โหลดเอง
- คลิปที่มีลายน้ำหรือเลขเวลาฝังในภาพ (เช่นพรีวิวของคลังเสียเงิน) ทิ้งแล้วหาตัวอื่น
- ภาพสต็อกที่ยืนแทนเหตุการณ์จริง เช่นภาพคนโวยวายทางโทรศัพท์ ขึ้นป้าย "ภาพจำลอง" บนจอทุกช็อต
- ตัวเลขและคำพูดที่ขึ้นจอต้องมีแหล่งต้นทางพร้อมปี Claude ส่งตัวช่วยไปตรวจให้ ผลอยู่ท้าย `CREDITS.md`

ถ้า Pexels ไม่ยอมให้โหลดคลิปบางตัว Claude จะส่งลิงก์ให้คุณกดดาวน์โหลดเองแล้วบอก path กลับมา

## มีม

มีมใช้ราว 3 ตัวต่อคลิป 60 วินาที วางตรงประโยคตบมุกหรือจังหวะรีแอ็กชัน ยาว 1.5–2.5 วินาที
ใช้แต่ภาพ ไม่เอาเสียงของมีมติดมา วางครึ่งบนของจอโดยหน้าคุณอยู่ครึ่งล่าง และติดป้ายที่มาทุกครั้ง
มีมไม่ทับช่วงที่โชว์หลักฐาน เช่นตัวเลขหรือขั้นตอน เพราะจะแย่งสายตาคนดู
ไฟล์ GIF ถูกแปลงเป็นวิดีโอก่อนใส่

มีมส่วนใหญ่ตัดมาจากหนังหรือรายการทีวีของคนอื่น Claude จึงไม่โหลดมีมจากเน็ตเองโดยไม่ถาม ในโหมด "ทำรวดเดียว" เป็นแบบนี้

1. ตั้งคลังมีมไว้แล้ว (หัวข้อถัดไป) ใช้ของในคลังได้เลย
2. ยังไม่มีคลัง Claude ใส่การ์ดข้อความหรือคำเด้งตรงจังหวะมุกแทน แล้วเขียนผู้สมัคร 3–5 ตัวลง `meme-candidates.md` (ลิงก์ · ช่อง · วางวินาทีไหน · ทำไมเข้า)
3. คุณเปิดดู ตอบว่าเอาตัวไหน แล้ว Claude โหลดและเรนเดอร์ใหม่

Claude จะไม่เอารูปปั้นหรือภาพวาดเก่ามาใส่แล้วเรียกว่ามีม

## คลังมีมและเสียงของคุณเอง

ถ้าคุณเก็บมีมกับเสียงเอฟเฟกต์ไว้ในโฟลเดอร์เดียว ทำเป็นคลังให้ Claude ค้นได้

ตั้งโฟลเดอร์คลังตอนติดตั้ง หรือพิมพ์ทีหลังว่า `ตั้งโฟลเดอร์คลังมีมเป็น <path เต็ม>` แล้วพิมพ์ `ทำคลังมีม`
Claude ทำ 4 ขั้น

| ขั้น | เกิดอะไรขึ้น |
|---|---|
| สแกน | อ่านไฟล์ `.mp4 .mov .gif .webp .png .jpg .jpeg .mp3 .wav .m4a` ให้เลขประจำตัว มีมเป็น `m001` เสียงเป็น `s001` |
| ดูภาพรวม | ทำภาพรวมหน้าละ 24 ช่อง มีเลขประจำตัวที่มุม Claude เปิดดูทุกช่อง |
| แท็ก | ใส่คำค้น 2–5 คำแบบความรู้สึกหรือสถานการณ์ ("ตกใจ" "เงินหาย") จังหวะที่ใช้ ระดับความเสี่ยง และโน้ตว่าใช้ตอนไหนถึงตลก |
| ค้น | ตอนตัดคลิป Claude ค้นจากความหมายของประโยคกับทรงของมุก ตัวที่แท็กแล้วขึ้นก่อน |

ระดับความเสี่ยงมี 3 ระดับ: `safe` ท่าทางหรือภาพทั่วไป · `caution` มาจากหนัง ทีวี เพลง หรือมีโลโก้หรือคนดังชัด ใช้โพสต์ปกติได้แต่ไม่ยิงแอด · `avoid` ห้ามใช้
ดูภาพแล้วไม่รู้ว่ามุกคืออะไร Claude จะถามคุณ ไม่เดาเอง

สอนคลังได้ด้วยประโยคธรรมดา

- `ตัวนี้ชอบ` ทำเป็นตัวโปรด ขึ้นก่อนเมื่อคะแนนสูสี
- `ตัวนี้อย่าใช้อีก` ตั้งเป็น avoid
- `m012 ใช้ตอนเจอตัวเลขที่ไม่คาดคิด ช่วงเด็ดวินาที 0.4 ถึง 1.6` เขียนโน้ตทับ
- `แท็กคลังต่อหน้า 2` ทำหน้าถัดไป

Claude ฟังเสียงไม่ได้ เสียงเอฟเฟกต์จึงแท็กจากชื่อไฟล์กับความยาว ไฟล์ที่ชื่อไม่บอกอะไร เช่น `sound-17.mp3` ให้คุณบอกว่าเป็นเสียงอะไร ถ้าในไฟล์มีคนพูด Claude ถอดข้อความมาช่วยแท็กได้
ป้ายทั้งหมดเก็บในโฟลเดอร์ `.tad-clip` ภายในโฟลเดอร์คลังของคุณ ตัวไฟล์ในคลัง Claude ไม่แตะ
เปลี่ยนชื่อไฟล์เมื่อไหร่ ไฟล์นั้นได้เลขใหม่และโน้ตเดิมไม่ตามไป ย้ายไฟล์ไปโฟลเดอร์ย่อยอื่นโดยใช้ชื่อเดิม เลขยังตามไป

## เสียงเอฟเฟกต์

ใส่เฉพาะเมื่อคุณเลือก "เสียงเอฟเฟกต์" ตอนเริ่ม Claude วางเสียงตรงมุกหรือรีแอ็กชัน ไม่ทับคำสำคัญ
ค่าเริ่มต้นคือเบากว่าเสียงพูด ณ จังหวะนั้น 8 dB เครื่องวัดความดังของแต่ละไฟล์เอง เพราะไฟล์เสียงดังไม่เท่ากัน ต่างกันได้ 25 dB ขึ้นไป
ยังดังไป พิมพ์ `เสียงเอฟเฟกต์เบาลงอีก` Claude ลดเป็น −12 dB แล้วมิกซ์ใหม่
เสียงพูดของคุณไม่ถูกปรับ และทุกคลิปผ่านตัวคุมเสียงพีคก่อนส่ง ไม่ว่าจะใส่เสียงเอฟเฟกต์หรือไม่
เสียงที่หามาจากเน็ตจดลง `CREDITS.md` เหมือนภาพ

## ลิขสิทธิ์โดยย่อ

`CREDITS.md` มีช่อง "ใช้ยิงแอดได้" ทุกแถว ตอบตามที่มาของชิ้นนั้น

| ที่มา | ใช้ยิงแอดได้ |
|---|---|
| คุณถ่ายหรือทำเอง | ใช่ |
| CC0 · public domain · CC BY (ใส่ชื่อเจ้าของ) | ใช่ |
| Pexels · Pixabay | ใช่ (มีโลโก้แบรนด์ในภาพถือว่าไม่แน่ใจ) |
| CC BY-SA | ไม่ (โพสต์ปกติได้พร้อมเครดิต) |
| หน้าทางการของแบรนด์ · ภาพข่าว | ไม่ |
| คลิป YouTube ของคนอื่น · หนัง · ทีวี · มีม · เพลง | ไม่ |
| ไลเซนส์ไม่ชัด | ไม่ |

โพสต์ปกติแบบเล่าเรื่องพร้อมเครดิตใช้ของที่ติด "ไม่" ได้ แต่ยังมีโอกาสโดนแจ้งลบหรือปิดเสียง
จะจ่ายเงินโปรโมตคลิปไหน เปลี่ยนทุกชิ้นที่ติด "ไม่" ก่อน
รายละเอียดเต็มและเรื่องเพลงอยู่ที่ [ลิขสิทธิ์ของที่แทรก](07-copyright.md)
