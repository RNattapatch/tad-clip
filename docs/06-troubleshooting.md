# เจอปัญหา

หาบรรทัดที่ตรงกับสิ่งที่คุณเห็นบนจอ แล้วทำตามช่องขวา
เกือบทุกปัญหาของเครื่องแก้ด้วยการพิมพ์ `ตรวจเครื่อง tad-clip` Claude จะรันตัวตรวจแล้วรันตัวติดตั้งซ้ำให้
ตัวติดตั้งรันซ้ำได้ปลอดภัย ของที่ลงแล้วจะข้าม โมเดลถอดเสียงที่โหลดค้างจะโหลดต่อจากเดิม ส่วนไฟล์โปรแกรมบน Windows ที่โหลดค้างจะเริ่มโหลดใหม่ Claude จะถามคุณก่อนถ้าต้องโหลดของเกิน 1 GB หรือต้องใช้รหัสผ่านเครื่อง

## ตอนเพิ่ม plugin

| เห็นอะไร | แก้ยังไง |
|---|---|
| พิมพ์ `ติดตั้ง tad-clip` หรือ `ตัดคลิป` แล้ว Claude ไม่รู้จัก ทำแบบอื่นไปเลย | plugin ยังไม่โหลด พิมพ์ `/reload-plugins` หรือปิดแอปแล้วเปิดใหม่ แล้วเช็คว่ามี tad-clip ในปุ่ม **+** → **Plugins** |
| `/plugin marketplace add` ขึ้น error | เช็คตัวสะกด `RNattapatch/tad-clip` กับการต่อเน็ต แล้วลองใหม่ |
| Windows: Claude รันคำสั่งด้วย PowerShell แล้วพังตั้งแต่บรรทัดแรกที่ขึ้นต้นด้วย `K="${CLAUDE_PLUGIN_ROOT}"` | เครื่องยังไม่มี Git for Windows ลงตามขั้นที่ 2 ใน [หน้าติดตั้ง Windows](02-install-windows.md) แล้วปิดเปิดแอปใหม่ |
| `tad-clip รองรับ macOS และ Windows เท่านั้น` | เครื่อง Linux ยังไม่รองรับ |
| งานหยุดนิ่ง ไม่มีอะไรขยับนานผิดปกติ | ดูในแชทว่ามีกล่องขออนุญาตรันคำสั่งค้างอยู่ไหม โหมด Manual จะรอคุณกดทุกคำสั่ง เปลี่ยนเป็นโหมด Auto ได้ที่ปุ่มข้างปุ่มส่ง |

## ตอนติดตั้งบน Mac

| เห็นอะไร | แก้ยังไง |
|---|---|
| `เครื่องนี้ยังไม่มี Homebrew` | ลง Homebrew ตามหัวข้อ "ถ้ายังไม่มี Homebrew" ใน [หน้าติดตั้ง Mac](01-install-mac.md) แล้วพิมพ์ `ติดตั้ง tad-clip ต่อ` |
| Terminal ขึ้น `is not in the sudoers` หรือ `Need sudo access` | บัญชีนี้ไม่ใช่ admin ล็อกอินบัญชี admin ของเครื่องแล้วลง Homebrew ใหม่ |
| ลง Homebrew เสร็จ แต่ Terminal ขึ้น `command not found: brew` | ยังไม่ได้วางคำสั่งในหัวข้อ `Next steps` ท้ายตัวติดตั้ง Homebrew ส่วน tad-clip หา Homebrew เจอเองอยู่แล้ว พิมพ์ `ติดตั้ง tad-clip ต่อ` ได้เลย |
| `brew install … ไม่สำเร็จ … ลองรัน brew update แล้วสั่งติดตั้งใหม่` | เปิด Terminal พิมพ์ `brew update` กด Enter รอจนจบ แล้วพิมพ์ใน Claude ว่า `ติดตั้ง tad-clip ต่อ` |
| มีหน้าต่างถามให้ติดตั้ง command line developer tools | กด "ติดตั้ง" รอราว 5–10 นาที ชุดนี้ใช้ตัดพื้นหลังคนด้วย Apple Vision |

## ตอนติดตั้งบน Windows

| เห็นอะไร | แก้ยังไง |
|---|---|
| `โปรแกรมกันไวรัสอาจกักไฟล์ไว้` หรือ `เรียก … แล้วไม่ตอบ` ตามด้วยไฟล์ใน `.tad-clip\bin` | เปิด Windows Security → Virus & threat protection → Protection history → เลือกรายการนั้น → Actions → Allow on device (หรือ Restore) แล้วพิมพ์ `ติดตั้ง tad-clip ต่อ` |
| `yt-dlp.exe เปิดไม่ได้ … ตัดคลิปได้ปกติ แค่โหลดคลิปจากเว็บไม่ได้` | ใช้งานต่อได้เลย ถ้าอยากให้โหลดคลิปจากเว็บได้ ปล่อยไฟล์ตามบรรทัดบนแล้วรันซ้ำ |
| `ไฟล์ zip ที่โหลดมาเสีย` | เน็ตหลุดระหว่างโหลด พิมพ์ `ติดตั้ง tad-clip ต่อ` |
| `ต่อ nodejs.org ไม่ได้` | เน็ตออกไปเว็บนี้ไม่ได้ เครือข่ายบริษัทบางที่บล็อกไว้ ลองเน็ตบ้านหรือฮอตสปอตมือถือแล้วสั่งใหม่ |
| `ถอดเสียงด้วยการ์ดจอไม่ผ่าน … ตั้งให้ใช้ CPU แทน` | ใช้งานได้ปกติแต่ช้ากว่า ถ้าเพิ่งอัปเดตไดรเวอร์การ์ดจอ NVIDIA พิมพ์ `ติดตั้ง tad-clip ต่อ` ตัวติดตั้งจะลองการ์ดจออีกรอบ |
| ถอดเสียงช้ามากบนเครื่องที่ไม่มีการ์ดจอ NVIDIA | เป็นเรื่องปกติ ขั้นนี้ช้ากว่า Mac หลายเท่า ใช้โหมด "ทำรวดเดียว" แล้วปล่อยเครื่องทำ หรือเปลี่ยนโมเดลเป็น medium |

## ตอนติดตั้ง ทั้ง Mac และ Windows

| เห็นอะไร | แก้ยังไง |
|---|---|
| `พื้นที่ว่างไม่พอ ต้องการประมาณ … GB` | ลบไฟล์ที่ไม่ใช้ หรือย้ายคลิปเก่าไปไดรฟ์อื่น แล้วพิมพ์ `ติดตั้ง tad-clip ต่อ` |
| โหลดโมเดลถอดเสียงค้าง หรือขึ้น `โหลด … ไม่สำเร็จ … (ส่วนที่โหลดแล้วไม่หาย)` | เช็คเน็ตแล้วพิมพ์ `ติดตั้ง tad-clip ต่อ` ไฟล์จะโหลดต่อจากส่วนที่ได้แล้ว ไม่เริ่มใหม่ |
| `หยุดกลางทาง — สั่งติดตั้งใหม่ได้ มันจะทำต่อจากที่ค้าง` | พิมพ์ `ติดตั้ง tad-clip ต่อ` |
| `หาเบราว์เซอร์สำหรับวาดการ์ดที่เปิดได้ไม่เจอ` | เช็คเน็ตแล้วสั่งติดตั้งใหม่ ตัวติดตั้งจะโหลด chrome-headless-shell ให้ ถ้ายังไม่ได้ ลง Google Chrome ตัวปกติแล้วลองอีกครั้ง |
| `ไฟล์ตั้งค่า config.json เปิดไม่ได้ (เนื้อในเสีย)` | ตัวติดตั้งเก็บไฟล์เดิมไว้เป็น `config.json.broken-<วันเวลา>` แล้วใช้ค่าเริ่มต้น บอก Claude ว่า `ย้ายค่าที่ตั้งไว้จากไฟล์ broken กลับมา` |
| `ติดตั้งสะดุด (…)` | สั่งติดตั้งใหม่ได้เลย ถ้าเจอซ้ำ เปิด Issue ตามหัวข้อท้ายหน้า |

## ตารางตรวจเครื่องมีแถวที่ไม่ผ่าน

ตารางนี้มาจาก `ตรวจเครื่อง tad-clip` ใต้ตารางจริงมีหัวข้อ "วิธีแก้" บอกคำสั่งเดียวต่อปัญหา ส่วนใหญ่คือรันตัวติดตั้งซ้ำ

| แถว | ข้อความที่เห็น | แก้ยังไง |
|---|---|---|
| การติดตั้ง | ❌ `ยังไม่ได้ติดตั้ง` | พิมพ์ `ติดตั้ง tad-clip` |
| การติดตั้ง | ❌ `ไฟล์ตั้งค่าเสีย อ่านไม่ได้` | พิมพ์ `ติดตั้ง tad-clip ต่อ` ค่าเดิมถูกเก็บเป็นไฟล์ `.broken` |
| Git Bash (ที่ Claude ใช้รันคำสั่ง) บน Windows | ❌ `ไม่พบ Git for Windows (bash.exe) — Claude Code บน Windows ใช้ตัวนี้รันคำสั่ง ถ้าไม่มี คำสั่งของ kit จะรันไม่ได้` | ลง Git for Windows ฟรีจาก [git-scm.com/download/win](https://git-scm.com/download/win) กด Next ตามค่าเริ่มต้นทุกหน้า ปิดแอป Claude แล้วเปิดใหม่ แล้วพิมพ์ `ติดตั้ง tad-clip` อีกครั้ง |
| Git Bash (ที่ Claude ใช้รันคำสั่ง) บน Mac | ℹ️ `ไม่ต้องใช้บน macOS` | ปกติ ไม่ต้องทำอะไร |
| ffmpeg (ตัดต่อ + ฝังซับ) | ❌ `ฝังซับไม่ได้ (ไม่มี libass…)` หรือ `เก่าเกินไป ต้องการ 5.1 ขึ้นไป` | ปล่อยให้ Claude รันตัวติดตั้งซ้ำ บน Mac จะลง `ffmpeg-full` ผ่าน Homebrew เพราะ ffmpeg ตัวปกติของ Homebrew ฝังซับไม่ได้ · บน Windows จะโหลดตัวที่ฝังซับได้มาแทน |
| ffmpeg · ffprobe · Node.js 22+ · yt-dlp | ❌ `ไม่พบ … ในเครื่อง` หรือ `เรียก … แล้วไม่ตอบ` | รันตัวติดตั้งซ้ำ บน Windows ดูเรื่องโปรแกรมกันไวรัสด้านบนด้วย |
| Node.js 22+ | ❌ `ต้องการ Node 22 ขึ้นไป (เครื่องนี้เป็น v…)` | รันตัวติดตั้งซ้ำ ตัวติดตั้งลง Node 22 ให้ |
| Python | ❌ `ยังไม่มี venv` หรือ `import ไม่ผ่าน` | รันตัวติดตั้งซ้ำ |
| ตัวถอดเสียง (Mac) | ❌ `ไม่พบ whisper-cli ในเครื่อง (whisper.cpp)` | รันตัวติดตั้งซ้ำ |
| โมเดลถอดเสียง | ❌ `ยังไม่ได้โหลด…` หรือ `โหลดมาไม่ครบ (… จาก … MB)` | รันตัวติดตั้งซ้ำ ไฟล์โหลดต่อจากเดิม |
| เบราว์เซอร์วาดการ์ด (Chrome/Edge) | ❌ `ไม่พบ Chrome, Edge หรือ chrome-headless-shell` หรือ `เปิดแล้วไม่ตอบภายใน 20 วิ` | รันตัวติดตั้งซ้ำ มันลองเบราว์เซอร์ตัวถัดไปเอง หรือโหลด chrome-headless-shell (โหลดราว 100 MB) มาให้ |
| ตัดพื้นหลังคน (cutout) บน Mac | ❌ `ยังไม่มี Xcode Command Line Tools` | ให้ Claude รัน `xcode-select --install` กด "ติดตั้ง" ในหน้าต่างที่ขึ้น รอ 5–10 นาที แล้วพิมพ์ `ตรวจเครื่อง tad-clip` |
| ตัดพื้นหลังคน (cutout) | ⚠️ `ตั้งไว้เป็น transparent-background แต่ยังไม่ได้ติดตั้ง` | พิมพ์ `ติดตั้งตัวตัดพื้นหลังเพิ่ม` หรือ `ตั้ง cutout กลับเป็น auto` |
| ตัดพื้นหลังคน (cutout) | ℹ️ `ปิดอยู่ (ไม่บังคับ)` | ปกติบน Windows ที่ไม่ได้ลงตัวเสริม ช็อตตัดพื้นหลังจะเป็นแบบแบ่งครึ่งจอแทน |
| พื้นที่ว่าง | ⚠️ `เหลือ … GB (แนะนำอย่างน้อย 15 GB)` | ตัดคลิปสั้นได้ คลิปยาวอาจไม่พอ ลบไฟล์ที่ไม่ใช้หรือย้ายคลิปเก่าออก |
| หน่วยความจำ (RAM) | ⚠️ `RAM … GB (น้อยกว่า 8 GB) — โมเดล large-v3 อาจช้าหรือค้าง เปลี่ยนเป็น medium จะเบากว่า` | พิมพ์ `เปลี่ยนโมเดลถอดเสียงเป็น medium` (โหลดเพิ่ม 1.5 GB) |

เครื่อง RAM 8 GB พอดีจะไม่ขึ้นเตือน แต่ถ้าถอดเสียงแล้วเครื่องหน่วงจนใช้งานอื่นไม่ได้ ก็เปลี่ยนเป็น medium ได้แบบเดียวกัน

## ตอนตัดคลิป

| เห็นอะไร | แก้ยังไง |
|---|---|
| Claude บอกว่าหาไฟล์คลิปไม่เจอ | ส่ง path เต็มของไฟล์ (Mac: คลิกไฟล์ใน Finder แล้ว Option+Cmd+C · Windows: คลิกขวา → Copy as path) ชื่อไทยและเว้นวรรคใช้ได้ |
| `ที่ว่างบนไดรฟ์ของคลิปน้อยกว่าที่ต้องใช้` | คลิปหนึ่งต้องการที่ว่างราว 3 เท่าของขนาดไฟล์บวก 5 GB บนไดรฟ์ที่เก็บคลิป ลบไฟล์ หรือย้ายคลิปไปไดรฟ์ที่ว่างกว่า |
| Claude บอกว่าคำสั่งหมดเวลา (`timed out`) หรือขั้นหนึ่งถูกตัดกลางทาง | คำสั่งที่รันแบบรอผลถูกตัดที่ 2 นาที พิมพ์ `รันขั้นนั้นใหม่แบบ background แล้วรอจนจบ` ขั้นที่เสร็จแล้วไม่ต้องทำซ้ำ |
| ซับหายไปทั้งช่วง ทั้งที่ในคลิปยังพูดอยู่ | พิมพ์ `ซับช่วงวินาทีที่ 45 ถึง 60 หายไป` Claude จะถอดเสียงเฉพาะช่วงนั้นใหม่แล้วเสียบกลับ |
| ชื่อคุณหรือชื่อแบรนด์ถอดผิดทุกคลิป | เพิ่มลงคลังคำ ดูหัวข้อคลังคำใน [หน้า 05](05-brand-style.md) |
| ซับหรือการ์ดเป็นสี่เหลี่ยม ตัวไทยเพี้ยน | ระบบหาฟอนต์ไม่เจอ พิมพ์ `ใช้ฟอนต์ Prompt กลับมา` ถ้าเคยใส่ฟอนต์เอง เช็คว่าไฟล์ฟอนต์ยังอยู่หลังอัปเดต |
| ข้อความบนการ์ดล้นกรอบ หรือตัดคำไทยกลางคำ | บอกเลขช็อตหรือวินาที เช่น `การ์ดวินาทีที่ 20 ข้อความล้น` Claude แก้แล้วเรนเดอร์ช็อตนั้นใหม่ |
| โหลดคลิปจากเว็บไม่ได้ ทั้งที่เคยได้ | เว็บเปลี่ยนบ่อย พิมพ์ `อัปเดตตัวโหลดคลิป` (Mac อัปเดต yt-dlp ผ่าน Homebrew · Windows สั่ง yt-dlp อัปเดตตัวเอง) |
| `Pexels ไม่มีไฟล์ของวิดีโอ …` | เปิดหน้าวิดีโอนั้นแล้วกดดาวน์โหลดเอง บอก path ให้ Claude |
| Claude บอกว่าหน้าเว็บต้องล็อกอินหรือติดระบบกันบอท | Claude จะไม่หาทางข้าม โหลดไฟล์เองแล้วส่ง path ให้ |

## หลังเรนเดอร์: ไม่มีเสียง จอดำ หรือคลิปสั้นผิด

พิมพ์ `ตรวจคลิป final.mp4 ให้หน่อย` Claude จะรันตัวตรวจคลิป 5 ข้อ ทุกครั้งก่อนส่งงาน Claude รันข้อนี้อยู่แล้ว แต่สั่งซ้ำได้

| ข้อ | ไม่ผ่านแปลว่าอะไร | แก้ยังไง |
|---|---|---|
| ความยาว | ยาวไม่เท่าคลิปที่ตัดเทคแล้ว (คลาดได้ไม่เกิน 0.25 วิ) | แผนภาพไม่ครอบทั้งคลิป Claude แก้แผนแล้วเรนเดอร์ใหม่ |
| ขนาดภาพ | ขนาดไม่ตรงกับที่ควรได้ ถ้าเลือกภาพประกอบ ขนาดต้องตาม preset (1080p = 1080×1920 · 2k60 = 1440×2560) ถ้าเลือกแค่ซับหรือตัด + ซับ ขนาดเท่าไฟล์ต้นฉบับ ซึ่งผ่าน QC ได้ | เช็คค่าความละเอียดใน [หน้า 05](05-brand-style.md) แล้วเรนเดอร์ใหม่ |
| มีเสียง | `ไฟล์นี้ไม่มีเสียง` | เปิดคลิปต้นฉบับฟังว่ามีเสียงไหม ถ้ามี ให้ Claude เรนเดอร์ใหม่ |
| ไม่มีจอดำ | `จอดำเกิน 0.5 วิ ที่ …` | ช็อตช่วงนั้นหาไฟล์ภาพไม่เจอ Claude ดูวินาทีที่บอก แก้แล้วเรนเดอร์ใหม่ |
| เสียงไม่พีค | `true peak … (เกิน -0.5 dBTP)` | เสียงอาจแตกตอนแพลตฟอร์มแปลงไฟล์ ให้ Claude รันขั้นมิกซ์เสียงซ้ำ ขั้นนี้มีตัวคุมพีค |

ตัวตรวจคลิปดูได้แค่ตัวเลข Claude จึงดึงภาพนิ่งอย่างน้อย 3 จุดมาเปิดดูเองด้วย ถ้าคุณเห็นอะไรผิดในคลิป บอกวินาทีที่เห็นได้เลย
