# ติดตั้ง tad-clip บน Windows

หน้านี้พาทำตั้งแต่เครื่องยังไม่มีอะไรเลย จนเห็นบรรทัด `ผล: พร้อมใช้ ✅`
ขั้น tad-clip ใช้เวลาราว 10–30 นาที ขึ้นกับเน็ต ส่วนใหญ่คือรอโหลดโมเดลถอดเสียง ตัว tad-clip ไม่ต้องใช้สิทธิ์ admin และไม่ต้องลง Python เอง

## ก่อนเริ่ม

| ต้องมี | รายละเอียด |
|---|---|
| แพ็กเกจ Claude | Pro ขึ้นไป แพ็กเกจฟรีไม่มีแท็บ Code |
| ระบบ | Windows 10 หรือ 11 แบบ 64-bit |
| RAM | 8 GB ขึ้นไป · 16 GB สบายกว่า |
| พื้นที่ว่าง | ราว 15 GB บนไดรฟ์ที่เก็บโฟลเดอร์ผู้ใช้ |
| การ์ดจอ NVIDIA | ไม่บังคับ มีแล้วถอดเสียงเร็วขึ้นมาก |

ดู RAM กับชนิดระบบได้ที่ Settings → System → About (การตั้งค่า → ระบบ → เกี่ยวกับ) ต้องเห็นคำว่า 64-bit
ดูการ์ดจอได้ที่ Task Manager (Ctrl+Shift+Esc) → แท็บ Performance → GPU ถ้ามีชื่อขึ้นต้นด้วย NVIDIA แปลว่ามี

## 1. ลงแอป Claude แล้วเปิดแท็บ Code

1. โหลดแอป Claude สำหรับ Windows ที่ [claude.ai/download](https://claude.ai/download) แล้วเปิดไฟล์ติดตั้ง
2. เปิดแอป ล็อกอินด้วยบัญชีที่มีแพ็กเกจ Pro ขึ้นไป
3. กดแท็บ **Code** ด้านบน
4. ก่อนพิมพ์ข้อความแรก ดูแถวเหนือช่องพิมพ์ ตั้ง Environment เป็น **Local** และ Project folder เป็นโฟลเดอร์ที่คุณเก็บคลิป เช่น Videos

ที่ต้องเลือกโฟลเดอร์คลิป เพราะ Claude จะสร้างโฟลเดอร์งานไว้ข้างไฟล์คลิปแต่ละไฟล์

## 2. ลง Git for Windows (ถ้ายังไม่มี)

คำสั่งทุกตัวของ tad-clip เขียนแบบ Bash
บน Windows ตัว Claude Code รันคำสั่ง Bash ผ่าน Git Bash ซึ่งมากับโปรแกรม Git for Windows ถ้าเครื่องไม่มี Claude จะใช้ PowerShell แทน และคำสั่งของ tad-clip จะรันไม่ขึ้น

เช็คก่อน: กดปุ่ม Start แล้วพิมพ์ `Git Bash` ถ้าเจอ ข้ามข้อนี้ได้

ถ้าไม่เจอ:

1. โหลดที่ [git-scm.com/download/win](https://git-scm.com/download/win)
2. เปิดไฟล์ติดตั้ง กด Next ไปจนจบได้เลย ค่าที่ตั้งมาใช้ได้
3. ปิดแอป Claude แล้วเปิดใหม่ ให้แอปเห็น Git ที่เพิ่งลง

ตัวติดตั้งของ Git อาจขอสิทธิ์ admin ถ้าเป็นเครื่องบริษัทที่คุณไม่มีสิทธิ์ ให้ฝ่าย IT ลงให้ ขั้นอื่นในหน้านี้ไม่ต้องใช้สิทธิ์ admin อีก

## 3. เพิ่ม plugin tad-clip

เลือกทางใดทางหนึ่ง

ทาง ก กดในแอป: ปุ่ม **+** ข้างช่องพิมพ์ → **Plugins** → **Add plugin** แล้วใส่ `RNattapatch/tad-clip`
ตอนเลือกขอบเขต ให้เลือกติดตั้งกับบัญชีของคุณ (user) จะได้ใช้ได้ทุกโฟลเดอร์

ทาง ข พิมพ์ในช่องแชท ทีละบรรทัด กด Enter หลังแต่ละบรรทัด

```
/plugin marketplace add RNattapatch/tad-clip
/plugin install tad-clip@pun-nattapatch
```

บรรทัดที่สองจะเปิดหน้ารายละเอียดของ plugin ก่อน เลือก **Install for you (user scope)**
ถ้าทาง ก หาช่องใส่ชื่อไม่เจอ ใช้ทาง ข ได้เลย

ติดตั้งเสร็จแล้วถ้าขึ้นว่า `Run /reload-plugins to apply` ให้พิมพ์ `/reload-plugins` หรือปิดแอปแล้วเปิดใหม่

## 4. พิมพ์ว่า "ติดตั้ง tad-clip"

พิมพ์ในช่องแชทว่า `ติดตั้ง tad-clip` แล้วกด Enter

สิ่งแรกที่ Claude ทำคือโหลด uv (ไฟล์ zip ราว 20 MB แตกแล้วใช้ที่ราว 45 MB) ลงโฟลเดอร์ `%USERPROFILE%\.tad-clip\bin` uv เป็นตัวติดตั้ง Python ที่ทำให้ไม่ต้องมี Python ในเครื่องมาก่อน
จากนั้นเช็คว่าเครื่องมีการ์ดจอ NVIDIA ไหม

### Claude บอกก่อนว่าจะลงอะไร

ก่อนติดตั้ง Claude จะสรุปรายการของที่จะลงพร้อมขนาดให้ดู ยังไม่มีอะไรถูกลงจนกว่าคุณจะตอบตกลง
บน Windows ทุกอย่างโหลดเป็นไฟล์ลงโฟลเดอร์ของ kit ไม่ผ่านตัวติดตั้งของ Windows

| ของที่ลง | ใช้ที่ในเครื่องโดยประมาณ |
|---|---|
| ffmpeg (ตัดต่อ + ฝังซับ) | 300 MB (โหลดไฟล์ zip ราว 200 MB) |
| Node.js 22 (วาดการ์ดข้อความ) | 90 MB |
| uv (ตัวติดตั้ง Python) | 45 MB |
| yt-dlp (โหลดคลิปจากเว็บเมื่อคุณอนุญาต) | 20 MB |
| Python 3.12 + faster-whisper + pythainlp | 700 MB |
| โมเดลถอดเสียง large-v3 | 3.1 GB |
| ไลบรารี CUDA (เฉพาะเครื่องที่มีการ์ดจอ NVIDIA) | 1.5 GB |
| เบราว์เซอร์วาดการ์ด | ใช้ Microsoft Edge ที่มีในเครื่อง ถ้าเปิดไม่ได้จึงโหลด chrome-headless-shell (โหลดราว 100 MB ใช้ที่ราว 300 MB) |

รวมราว 4.1 GB ถ้าไม่มีการ์ดจอ NVIDIA และราว 5.6 GB ถ้ามี
ของที่มีแล้วจะขึ้นว่า "มีแล้ว ข้าม" ถ้าพื้นที่ว่างไม่พอ ตัวติดตั้งจะหยุดและบอกว่าต้องลบไฟล์ออกเท่าไหร่
ไม่อยากโหลดไลบรารี CUDA บอก Claude ว่า "ไม่ต้องใช้การ์ดจอ" ระบบจะถอดเสียงด้วย CPU

### คำถามก่อนเริ่ม

1. เริ่มติดตั้งเลยไหม
2. โมเดลถอดเสียง: **large-v3** แม่นที่สุด 3.1 GB (แนะนำ) หรือ **medium** 1.5 GB เบากว่า ถอดภาษาไทยได้ แต่ฟังพลาดมากกว่า large-v3 ชัดเจน ซับจะมีคำให้แก้มากขึ้น เครื่องที่ RAM น้อยกว่า 8 GB ตัวติดตั้งเลือก medium ให้เอง
3. ตัวตัดพื้นหลังคน (ไม่บังคับ) ใช้กับช็อตที่ตัวคุณลอยอยู่บนภาพประกอบ

| เครื่องคุณ | ตัวเลือกที่ Claude เสนอ |
|---|---|
| มีการ์ดจอ NVIDIA | ติดตั้งเพิ่มราว 5 GB ใช้การ์ดจอ เร็ว · หรือไม่เอา |
| ไม่มี | ติดตั้งเพิ่มราว 2 GB ใช้ CPU ได้ผลเท่ากันแต่ช้ามาก ช็อตสั้นๆ ก็หลายนาที · หรือไม่เอา (แนะนำ) |

ไม่ติดตั้งก็ตัดคลิปได้ครบทุกอย่าง ช็อตแบบตัดพื้นหลังจะเปลี่ยนเป็นแบบแบ่งครึ่งจอ (ภาพครึ่งบน คุณครึ่งล่าง) แทน
ถ้าเลือกติดตั้ง ระบบจะโหลดน้ำหนักโมเดลตัดพื้นหลังอีกราว 370 MB ตอนติดตั้ง
อยากเพิ่มทีหลัง พิมพ์ `ติดตั้งตัวตัดพื้นหลังเพิ่ม`

### ระหว่างรอ Claude ถามการตั้งค่า

การติดตั้งรันอยู่เบื้องหลัง ระหว่างนั้น Claude ถาม 5 ข้อในครั้งเดียว ข้ามข้อไหนก็ได้ ระบบใช้ค่าเริ่มต้นแทน

1. ชื่อที่จะขึ้นในคลิป กับชื่อบัญชี เช่น `สมชาย ใจดี` กับ `@somchai.sales`
2. สีการ์ดข้อความ: `neutral` เทาเข้มเกือบดำ ตัวเน้นส้ม (ค่าเริ่มต้น) · `paper` พื้นครีม ตัวเน้นแดงอิฐ · `pun-navy-coral` กรมท่ากับชมพูแดง · หรือบอกรหัสสีแบรนด์เอง หรือส่งโลโก้ให้ Claude เลือกสีให้
3. คำที่ตัวถอดเสียงมักฟังผิด เช่น ชื่อคุณ ชื่อร้าน ชื่อสินค้า ศัพท์อังกฤษที่พูดบ่อย
4. โฟลเดอร์ที่เก็บมีมหรือเสียงเอฟเฟกต์ ไม่มีก็ได้ (บน Windows ใช้ `/` คั่นได้ เช่น `C:/Users/somchai/Videos/meme`)
5. ความละเอียดไฟล์: 1080p (แนะนำ เร็ว ไฟล์เล็ก) หรือ 2K 60fps (คมกว่า เรนเดอร์นานขึ้น)

ค่าทั้งหมดเปลี่ยนทีหลังได้ ดู [สี ฟอนต์ ตำแหน่งซับ](05-brand-style.md)

### 5 ขั้นของการติดตั้ง

| ขั้น | ทำอะไร |
|---|---|
| `[1/5]` โปรแกรมหลัก | โหลด ffmpeg, Node.js, uv, yt-dlp ลง `bin` |
| `[2/5]` Python 3.12 + ตัวถอดเสียง | ลง Python แยกของ kit ไม่ยุ่งกับ Python ตัวอื่นในเครื่อง |
| `[2b/5]` ตัวตัดพื้นหลัง | มีขั้นนี้เฉพาะเมื่อคุณเลือกติดตั้ง |
| `[3/5]` เบราว์เซอร์วาดการ์ด | ลองเปิด Edge ถ้าไม่ได้จึงโหลด chrome-headless-shell |
| `[4/5]` โมเดลถอดเสียง | ไฟล์ 3.1 GB นานที่สุด ถ้าเน็ตหลุด สั่งใหม่แล้วมันทำต่อจากที่ค้าง |
| `[5/5]` ตรวจเครื่อง | รันตัวตรวจ (doctor) |

เครื่องที่มีการ์ดจอ NVIDIA ตัวติดตั้งจะลองถอดเสียงสั้นๆ ด้วยการ์ดจอให้ ผ่านก็ใช้การ์ดจอ ไม่ผ่านก็ตั้งให้ใช้ CPU เอง คุณไม่ต้องทำอะไร

## โปรแกรมกันไวรัส

คุณไม่ต้องดับเบิลคลิกเปิดไฟล์ .exe ไหนเอง Claude เรียกใช้ผ่านคำสั่งทั้งหมด
บางเครื่อง Windows Security กักไฟล์ที่เพิ่งโหลดไว้ ตัวที่โดนบ่อยคือ `yt-dlp.exe` ถ้าเป็นแบบนี้ ตัวติดตั้งหรือตัวตรวจจะขึ้นข้อความว่า "โปรแกรมกันไวรัสอาจกักไฟล์ไว้"

วิธีปล่อยไฟล์:

1. เปิด Windows Security (ความปลอดภัยของ Windows)
2. Virus & threat protection → Protection history
3. เลือกรายการที่เป็นไฟล์ใน `.tad-clip\bin` → Actions → Allow on device (หรือ Restore)
4. กลับมาพิมพ์ใน Claude ว่า `ติดตั้ง tad-clip ต่อ`

ถ้า `yt-dlp.exe` ยังโดนกัก tad-clip ยังตัดคลิปได้ปกติ เสียแค่การโหลดคลิปจากเว็บมาแทรก
ส่วน ffmpeg, Node.js, uv ต้องปล่อยให้ได้ ไม่งั้นตัดคลิปไม่ได้

## ตอน Claude ขออนุญาตรันคำสั่ง

ในแท็บ Code มีปุ่มเลือกโหมดสิทธิ์อยู่ข้างปุ่มส่ง
โหมด Manual จะถามคุณก่อนรันทุกคำสั่ง การติดตั้งกับการตัดคลิปมีหลายคำสั่ง คุณจะต้องกดอนุญาตหลายครั้ง
ถ้าอยากปล่อยให้ทำจนจบโดยไม่ต้องเฝ้า เลือกโหมด Auto (ถ้าบัญชีของคุณมีให้เลือก) Claude จะรันเองโดยมีตัวตรวจว่าคำสั่งตรงกับที่คุณสั่ง

## ความเร็วบนเครื่องที่ไม่มีการ์ดจอ NVIDIA

ขั้นถอดเสียงช้ากว่า Mac หลายเท่า
ทางที่ใช้ได้จริง: เลือกโหมด "ทำรวดเดียว" แล้วปล่อยเครื่องทำไป · เลือก "ตัด + ซับ" ก่อนถ้าอยากได้งานเร็ว · ถ้ายังช้าเกินรับได้ เปลี่ยนโมเดลเป็น medium (บอก Claude ว่า `เปลี่ยนโมเดลถอดเสียงเป็น medium`) ถอดเร็วขึ้นราว 2 เท่า แลกกับฟังพลาดมากขึ้น

## ของที่ลงไปอยู่ตรงไหน

ทุกอย่างอยู่ใน `%USERPROFILE%\.tad-clip` (เช่น `C:\Users\somchai\.tad-clip`) ไม่มีอะไรลงใน Program Files และ Python ของ kit ไม่ลงทะเบียนกับ Windows

| โฟลเดอร์ | มีอะไร |
|---|---|
| `bin\` | `ffmpeg.exe` `ffprobe.exe` `node.exe` `uv.exe` `yt-dlp.exe` |
| `python\` | Python 3.12 |
| `venv\` | แพ็กเกจ Python ของ kit |
| `models\` | โมเดลถอดเสียง |
| `cache\` | แคชดาวน์โหลด |
| `chrome\` | มีเฉพาะเมื่อ Edge เปิดไม่ได้ |
| `.transparent-background\` | น้ำหนักโมเดลตัดพื้นหลัง (เฉพาะเมื่อลงตัวเสริม) |
| `config.json` | ค่าที่คุณตั้งไว้ |
