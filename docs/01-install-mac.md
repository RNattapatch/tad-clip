# ติดตั้ง tad-clip บน Mac

หน้านี้พาทำตั้งแต่เครื่องยังไม่มีอะไรเลย จนเห็นบรรทัด `ผล: พร้อมใช้ ✅`
ขั้น tad-clip ใช้เวลาราว 10–30 นาที ขึ้นกับเน็ต ส่วนใหญ่คือรอโหลดโมเดลถอดเสียง ถ้าเครื่องยังไม่มี Homebrew บวกอีก 5–15 นาที

## ก่อนเริ่ม

| ต้องมี | รายละเอียด |
|---|---|
| แพ็กเกจ Claude | Pro ขึ้นไป แพ็กเกจฟรีไม่มีแท็บ Code |
| เครื่อง | Mac แนะนำชิป Apple M1 ขึ้นไป |
| RAM | 8 GB ขึ้นไป · 16 GB สบายกว่า |
| พื้นที่ว่าง | ราว 15 GB |
| บัญชีผู้ใช้ของเครื่อง | ต้องเป็นบัญชี admin เฉพาะเมื่อเครื่องยังไม่มี Homebrew เพราะการลง Homebrew ต้องใช้รหัสผ่านเครื่อง |

ดูชิปกับ RAM ได้ที่เมนู Apple มุมซ้ายบน → เกี่ยวกับ Mac เครื่องนี้ (About This Mac)
พื้นที่ 15 GB แบ่งเป็นของที่ติดตั้งราว 5.6 GB (โมเดลถอดเสียงคนเดียว 3.1 GB) ที่เหลือเผื่อไฟล์งานตอนตัดคลิป

## 1. ลงแอป Claude แล้วเปิดแท็บ Code

1. โหลดแอป Claude สำหรับ Mac ที่ [claude.ai/download](https://claude.ai/download) เปิดไฟล์ แล้วลากไอคอน Claude เข้าโฟลเดอร์ Applications
2. เปิดแอป ล็อกอินด้วยบัญชีที่มีแพ็กเกจ Pro ขึ้นไป
3. กดแท็บ **Code** ด้านบน
4. ก่อนพิมพ์ข้อความแรก ดูแถวเหนือช่องพิมพ์ ตั้ง Environment เป็น **Local** และ Project folder เป็นโฟลเดอร์ที่คุณเก็บคลิป เช่น Movies

ที่ต้องเลือกโฟลเดอร์คลิป เพราะ Claude จะสร้างโฟลเดอร์งานไว้ข้างไฟล์คลิปแต่ละไฟล์

## 2. เพิ่ม plugin tad-clip

เลือกทางใดทางหนึ่ง

ทาง ก กดในแอป: ปุ่ม **+** ข้างช่องพิมพ์ → **Plugins** → **Add plugin** แล้วใส่ `RNattapatch/tad-clip`
ตอนเลือกขอบเขต ให้เลือกติดตั้งกับบัญชีของคุณ (user) จะได้ใช้ได้ทุกโฟลเดอร์

ทาง ข พิมพ์ในช่องแชท ทีละบรรทัด กด Enter หลังแต่ละบรรทัด

```
/plugin marketplace add RNattapatch/tad-clip
/plugin install tad-clip@pun-nattapatch
```

บรรทัดที่สองจะเปิดหน้ารายละเอียดของ plugin ก่อน เลือก **Install for you (user scope)**
ถ้าทาง ก หาช่องใส่ชื่อไม่เจอ ใช้ทาง ข ได้เลย

ติดตั้งเสร็จแล้วถ้าขึ้นว่า `Run /reload-plugins to apply` ให้พิมพ์ `/reload-plugins` หรือปิดแอปแล้วเปิดใหม่

## 3. พิมพ์ว่า "ติดตั้ง tad-clip"

พิมพ์ในช่องแชทว่า `ติดตั้ง tad-clip` แล้วกด Enter
Claude จะเช็คก่อนว่าเครื่องมี Homebrew หรือยัง Homebrew คือตัวติดตั้งโปรแกรมฟรีของ Mac ที่ tad-clip ใช้ลง ffmpeg, Node.js และตัวถอดเสียง

### ถ้ายังไม่มี Homebrew

Claude จะหยุดแล้วส่งคำสั่ง 1 บรรทัดมาให้ ขั้นนี้คุณต้องทำเอง เพราะต้องพิมพ์รหัสผ่านเครื่อง ซึ่ง Claude พิมพ์แทนไม่ได้

1. กด Cmd+Space พิมพ์ `Terminal` แล้วกด Enter
2. วางบรรทัดนี้ (เหมือนที่ [brew.sh](https://brew.sh) ให้ไว้) แล้วกด Enter

   ```
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

3. ขึ้นคำว่า `Password:` ให้พิมพ์รหัสที่ใช้เข้าเครื่อง แล้วกด Enter ตอนพิมพ์ตัวอักษรจะไม่ขึ้นบนจอ เป็นเรื่องปกติ
4. ขึ้นว่า `Press RETURN/ENTER to continue` ให้กด Enter อีกครั้ง แล้วรอ 5–15 นาที จนเห็น `Installation successful`
5. ท้ายสุดจะมีหัวข้อ `Next steps` พร้อมคำสั่งสั้นๆ ไม่กี่บรรทัดที่ขึ้นต้นด้วย `echo` หรือ `eval` ก๊อปไปวางใน Terminal แล้วกด Enter ทีละบรรทัด ขั้นนี้ทำให้เครื่องรู้จักคำสั่ง `brew`

กลับมาที่แอป Claude แล้วพิมพ์ `ติดตั้ง tad-clip ต่อ`

ลืมขั้น 5 ก็ยังติดตั้งต่อได้ เพราะ tad-clip หา Homebrew ใน `/opt/homebrew` กับ `/usr/local` เองอยู่แล้ว
ถ้า Terminal ขึ้นว่า `is not in the sudoers` หรือ `Need sudo access` แปลว่าบัญชีที่ใช้อยู่ไม่ใช่ admin ให้ล็อกอินบัญชี admin ของเครื่องแล้วทำใหม่

### Claude บอกก่อนว่าจะลงอะไร

ก่อนติดตั้ง Claude จะสรุปรายการของที่จะลงพร้อมขนาดให้ดู ยังไม่มีอะไรถูกลงจนกว่าคุณจะตอบตกลง
บนเครื่องที่ยังไม่มีอะไรเลย รายการจะประมาณนี้

| ของที่ลง | ใช้ที่ในเครื่องโดยประมาณ | ลงที่ |
|---|---|---|
| ffmpeg ตัวเต็ม (ตัดต่อ + ฝังซับ) | 1,000 MB | Homebrew |
| Node.js 22 (วาดการ์ดข้อความ) | 250 MB | Homebrew |
| uv (ตัวติดตั้ง Python) | 50 MB | Homebrew |
| yt-dlp (โหลดคลิปจากเว็บเมื่อคุณอนุญาต) | 350 MB | Homebrew |
| whisper.cpp (ถอดเสียงด้วยชิปกราฟิกของ Mac) | 40 MB | Homebrew |
| Python 3.12 + pythainlp + faster-whisper สำรอง | 700 MB | `~/.tad-clip/venv` |
| โมเดลถอดเสียง large-v3 | 3.1 GB | `~/.tad-clip/models` |
| chrome-headless-shell จาก Google (วาดการ์ด) | 300 MB (โหลดราว 100 MB) | `~/.tad-clip/chrome` |

รวมราว 5.6 GB ของที่เครื่องมีอยู่แล้วจะขึ้นว่า "มีแล้ว ข้าม" และไม่นับในยอดนี้
ถ้าพื้นที่ว่างน้อยกว่าที่ต้องใช้บวกอีก 1 GB ตัวติดตั้งจะหยุดและบอกว่าต้องลบไฟล์ออกเท่าไหร่

### คำถาม 2 ข้อก่อนเริ่ม

1. เริ่มติดตั้งเลยไหม
2. โมเดลถอดเสียง: **large-v3** แม่นที่สุด 3.1 GB (แนะนำ ใช้กับทุกเครื่อง) หรือ **medium** 1.5 GB เป็นทางสุดท้าย ถอดภาษาไทยได้ แต่ฟังพลาดมากกว่า large-v3 ชัดเจน และพลาดไม่เท่ากันในแต่ละเครื่อง

เครื่องที่ RAM น้อยกว่า 8 GB ก็ได้ large-v3 เหมือนกัน (ใช้ RAM ราว 3 GB) อาจช้าลง ปิดโปรแกรมอื่นก่อนถอดเสียง ตัวติดตั้งไม่เลือก medium ให้เอง
ไม่มี large-v3-turbo ให้เลือก เพราะตัวนี้ถอดภาษาไทยได้แย่
บน Mac ไม่มีคำถามเรื่องตัวตัดพื้นหลังคน เพราะใช้ Apple Vision ที่มากับเครื่อง

### ระหว่างรอ Claude ถามการตั้งค่า

การติดตั้งรันอยู่เบื้องหลัง ระหว่างนั้น Claude ถาม 5 ข้อในครั้งเดียว ข้ามข้อไหนก็ได้ ระบบใช้ค่าเริ่มต้นแทน

1. ชื่อที่จะขึ้นในคลิป กับชื่อบัญชี เช่น `สมชาย ใจดี` กับ `@somchai.sales`
2. สีการ์ดข้อความ: `neutral` เทาเข้มเกือบดำ ตัวเน้นส้ม (ค่าเริ่มต้น) · `paper` พื้นครีม ตัวเน้นแดงอิฐ · `pun-navy-coral` กรมท่ากับชมพูแดง · หรือบอกรหัสสีแบรนด์เอง หรือส่งโลโก้ให้ Claude เลือกสีให้
3. คำที่ตัวถอดเสียงมักฟังผิด เช่น ชื่อคุณ ชื่อร้าน ชื่อสินค้า ศัพท์อังกฤษที่พูดบ่อย
4. โฟลเดอร์ที่เก็บมีมหรือเสียงเอฟเฟกต์ ไม่มีก็ได้
5. ความละเอียดไฟล์: 1080p (แนะนำ เร็ว ไฟล์เล็ก) หรือ 2K 60fps (คมกว่า เรนเดอร์นานขึ้น)

ค่าทั้งหมดเปลี่ยนทีหลังได้ ดู [สี ฟอนต์ ตำแหน่งซับ](05-brand-style.md)

### 5 ขั้นของการติดตั้ง

Claude จะบอกเมื่อขึ้นขั้นใหม่

| ขั้น | ทำอะไร | หมายเหตุ |
|---|---|---|
| `[1/5]` โปรแกรมหลัก | `brew install` ffmpeg, Node.js, uv, yt-dlp, whisper.cpp | ครั้งแรกหลายนาที |
| `[2/5]` Python 3.12 + ตัวถอดเสียง | สร้างที่เก็บ Python แยกของ kit | ไม่ยุ่งกับ Python ตัวอื่นในเครื่อง |
| `[3/5]` เบราว์เซอร์วาดการ์ด | โหลด chrome-headless-shell ราว 100 MB แตกไฟล์แล้วใช้ที่ราว 300 MB | ถ้าโหลดไม่ได้ จะใช้ Google Chrome ที่มีอยู่แทน |
| `[4/5]` โมเดลถอดเสียง | โหลดไฟล์ 3.1 GB มีตัวเลข % ให้ดู | นานที่สุด ถ้าเน็ตหลุด สั่งใหม่แล้วมันโหลดต่อจากเดิม |
| `[5/5]` ตรวจเครื่อง | รันตัวตรวจ (doctor) | ดูหัวข้อถัดไป |

โหลดโมเดลครั้งเดียว หลังจากนั้นถอดเสียงได้โดยไม่ต้องต่อเน็ต แต่ตัว Claude ยังต้องต่อเน็ตตอนทำงาน
บน Mac ชิป M ตัวถอดเสียงวิ่งบนชิปกราฟิก คลิป 20 วินาทีถอดเสร็จในราว 20 วินาที

## 4. รอจนขึ้นคำว่า พร้อมใช้

ขั้นสุดท้าย ตัวติดตั้งพิมพ์ตารางตรวจเครื่องออกมา แล้ว Claude สรุปเป็นภาษาง่ายๆ ให้
บรรทัดที่ต้องเห็นคือ `ผล: พร้อมใช้ ✅`

<details>
<summary>ตารางตรวจเครื่องบน Mac หน้าตาประมาณนี้</summary>

```
ตรวจเครื่อง tad-clip · macOS … (arm64) · ที่เก็บ /Users/<ชื่อคุณ>/.tad-clip

| สถานะ | รายการ | ผล |
|---|---|---|
| ✅ | การติดตั้ง | /Users/<ชื่อคุณ>/.tad-clip |
| ℹ️ | Git Bash (ที่ Claude ใช้รันคำสั่ง) | ไม่ต้องใช้บน macOS |
| ✅ | ffmpeg (ตัดต่อ + ฝังซับ) | … |
| ✅ | ffprobe (อ่านข้อมูลไฟล์) | … |
| ✅ | Node.js 22+ | … |
| ✅ | Python + แพ็กเกจของ kit | … |
| ✅ | ตัวถอดเสียง | whisper.cpp (ชิปกราฟิกของ Mac) · … |
| ✅ | โมเดลถอดเสียง large-v3 (whisper.cpp) | … |
| ✅ | เบราว์เซอร์วาดการ์ด (Chrome/Edge) | … |
| ✅ | yt-dlp (โหลดคลิปจากเว็บ) | … |
| ✅ | ตัดพื้นหลังคน (cutout) | Apple Vision · … |
| ✅ | พื้นที่ว่าง | เหลือ … GB |
| ✅ | หน่วยความจำ (RAM) | … GB |

ผล: พร้อมใช้ ✅
```

</details>

แถว Git Bash ขึ้น ℹ️ บน Mac เป็นเรื่องปกติ แถวนี้ใช้กับ Windows เท่านั้น
ถ้ามีแถวไหนเป็น ❌ ใต้ตารางจะมีหัวข้อ "วิธีแก้" บอกคำสั่งเดียวต่อปัญหา ส่วนใหญ่ Claude ทำให้ได้เลย
แถวที่อาจเจอบน Mac คือ "ตัดพื้นหลังคน" ขึ้นว่ายังไม่มี Xcode Command Line Tools ให้ Claude รัน `xcode-select --install` จะมีหน้าต่างขึ้นมา กด "ติดตั้ง" รอราว 5–10 นาที แล้วพิมพ์ `ตรวจเครื่อง tad-clip`
ปัญหาอื่นดูที่ [เจอปัญหา](06-troubleshooting.md)

อยากเช็คเครื่องอีกเมื่อไหร่ พิมพ์ `ตรวจเครื่อง tad-clip` ได้ทุกเมื่อ

## ตอน Claude ขออนุญาตรันคำสั่ง

ในแท็บ Code มีปุ่มเลือกโหมดสิทธิ์อยู่ข้างปุ่มส่ง
โหมด Manual จะถามคุณก่อนรันทุกคำสั่ง การติดตั้งกับการตัดคลิปมีหลายคำสั่ง คุณจะต้องกดอนุญาตหลายครั้ง
ถ้าอยากปล่อยให้ทำจนจบโดยไม่ต้องเฝ้า เลือกโหมด Auto (ถ้าบัญชีของคุณมีให้เลือก) Claude จะรันเองโดยมีตัวตรวจว่าคำสั่งตรงกับที่คุณสั่ง

## ของที่ลงไปอยู่ตรงไหน

| อะไร | อยู่ที่ |
|---|---|
| ffmpeg, Node.js, uv, yt-dlp, whisper.cpp | Homebrew (`/opt/homebrew` บนชิป Apple · `/usr/local` บนชิป Intel) โปรแกรมอื่นในเครื่องใช้ร่วมได้ |
| Python ของ kit, โมเดลถอดเสียง, เบราว์เซอร์วาดการ์ด, แคช, ไฟล์ตั้งค่า `config.json` | `~/.tad-clip` |
| ตัว plugin | โฟลเดอร์ plugin ของ Claude (แอปดูแลเอง) |

โฟลเดอร์ `.tad-clip` ขึ้นต้นด้วยจุด Finder จึงซ่อนไว้ กด Cmd+Shift+. ในหน้าต่าง Finder เพื่อให้เห็น
ลบทิ้งทั้งหมดได้ทีหลัง ดูที่ [อัปเดตและถอนการติดตั้ง](08-update.md)
