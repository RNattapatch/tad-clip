# QC ก่อนส่ง final.mp4

## 1. เครื่องตรวจ
```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
"$PY" engine/doctor.py --qc "$W/final.mp4"
```
ต้องผ่านทุกข้อ: ความยาวตรงกับ roughcut.mp4 ในโฟลเดอร์เดียวกัน (±0.25 วิ · ถ้าผู้ใช้ตัดเองมา ใส่ `--expect-duration`) · ขนาด 1080×1920 หรือ 1440×2560 · มีเสียง · ไม่มีจอดำนานกว่า 0.5 วิ · เสียงไม่พีคเกิน −0.5 dBTP
ข้อไหนไม่ผ่าน → แก้ต้นเหตุแล้วเรนเดอร์ใหม่ ห้ามส่งไปก่อน

## 2. ดูด้วยตา (เปิดภาพดูเองทุกครั้ง)
ดึงเฟรมอย่างน้อย 3 จุด: วินาทีที่ 1 · กลางคลิป · ช่วงที่มีภาพแทรกหนักที่สุด
```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
"$FF" -v error -ss <วินาที> -i "$W/final.mp4" -frames:v 1 -vf scale=540:-1 "$W/out/qc-<วินาที>.jpg"
```

เช็ค:
- ซับอ่านออก ไม่ตกขอบ ไม่ถูกการ์ด/ภาพทับ · ไม่อยู่ในเขตปุ่มของแอป (ล่าง ~25% กับบน ~15% ของจอบน TikTok/Reels)
- หน้าคนพูดไม่ถูกการ์ดบัง · ในช่วง split ซับอยู่ใต้รอยต่อ
- ข้อความไทยไม่ขาดกลางคำ ไม่ล้นกรอบ
- ภาพจริงที่อ้างตัวเลข/คำพูดมีป้ายแหล่งที่มา
- ไม่มีลายน้ำ timecode หรือซับซ้อนของคลิปต้นทาง

## 3. ฟังจุดเสียงเอฟเฟกต์
ทุกจุดใน `sfx.json` ต้องไม่กลบคำสำคัญ ถ้าไม่แน่ใจให้ลด `db` เป็น −12 แล้วมิกซ์ใหม่
