# คลังมีม + เสียง + หาของมาแทรก (tad-clip-library) — by @pun_nattapatch

skill นี้ทำ 3 อย่าง

- ส่วน A: สร้างและดูแลคลังมีม/ภาพ/เสียงของผู้ใช้เอง (สแกนโฟลเดอร์ → ดูภาพรวม → แท็ก)
- ส่วน B: เลือกมีมกับเสียงจากคลังไปวางในคลิป แล้วมิกซ์เสียงเอฟเฟกต์
- หัวข้อ "หาของมาแทรก": กติกาหาภาพจริง คลิปจริง มีม เสียง จากเน็ตหรือจากโฟลเดอร์ของผู้ใช้ ที่ skill `tad-clip` เรียกใช้ในขั้นภาพประกอบ อ่านหัวข้อนี้ให้จบก่อนไปหาของจากเน็ตทุกครั้ง

kit นี้ไม่มีคลังมีมแถมมาให้ (ไม่มีสิทธิ์แจกต่อ) คลังคือโฟลเดอร์ของผู้ใช้เอง

## ท่อนเริ่มต้นของทุกบล็อก Bash

Bash tool จำตัวแปรและฟังก์ชันข้ามคำสั่งไม่ได้ ดังนั้นทุกบล็อก Bash ในไฟล์นี้ต้องขึ้นต้นด้วยบรรทัดนี้ ตัวอักษรต่อตัวอักษร

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
```

บรรทัดนี้โหลด `engine/env.sh` ของ kit ซึ่งตั้ง `KIT` (โฟลเดอร์ kit และ `cd` เข้าไปให้เลย) `TC_HOME` `PY` (python ของ kit) `FF` (ffmpeg ของ kit) `NODE` · ถ้า `${CLAUDE_PLUGIN_ROOT}` ไม่ถูกแทนค่า ให้ใช้ `~/.tad-clip/kit` (บรรทัดนี้ทำให้แล้ว) · เพราะมี `cd` ทุก path ของไฟล์ผู้ใช้ต้องเป็น path เต็ม และครอบด้วย `"..."` (ชื่อภาษาไทยและช่องว่างได้) · ทุกคำสั่ง ffmpeg ใช้ `"$FF"` เพราะบนเครื่องที่เพิ่งติดตั้ง ffmpeg ไม่อยู่ใน PATH

บล็อกที่ต้องใช้โฟลเดอร์งานของคลิปมีบรรทัดที่สองคือ `W="..."` ให้แทนด้วย path จริงทุกครั้ง `W` คือ `<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อไฟล์วิดีโอไม่มีนามสกุล>` เมื่อถูกเรียกจาก skill `tad-clip` ให้ใช้ path เดียวกับที่ `tad-clip` ใช้ · ถ้าใช้ skill นี้ตามลำพัง (ผู้ใช้แค่สั่งให้หามีมหรือภาพ) ให้ถามผู้ใช้ก่อนว่าของที่หามาจะใส่ให้คลิปไหน แล้วกำหนด `W` ตามนั้น และสร้างโฟลเดอร์ด้วย `mkdir -p "$W/assets/proof" "$W/assets/footage" "$W/assets/memes" "$W/assets/sfx"` (ในบล็อกที่ขึ้นต้นด้วยสองบรรทัดนี้) · ส่วน A (คลัง) ไม่ใช้ `W`

เครื่องมือที่ใช้ในไฟล์นี้

| คำสั่งที่เขียนในบล็อก | ไฟล์ | ทำอะไร |
|---|---|---|
| `"$NODE" engine/library.mjs <คำสั่ง>` | `${CLAUDE_PLUGIN_ROOT}/engine/library.mjs` | `index` `sheet` `tag` `search` `sounds` `show` `stats` |
| `"$PY" -m engine.fetch <คำสั่ง>` | `${CLAUDE_PLUGIN_ROOT}/engine/fetch.py` | `commons` `ytsearch` `video` `image` `gif2clip` `sheet` `scenes` `credit` `fact` `credits-summary` |
| `"$PY" -m engine.sfx_mix <video> <sfx.json> <out>` | `${CLAUDE_PLUGIN_ROOT}/engine/sfx_mix.py` | มิกซ์เสียงเอฟเฟกต์ใต้เสียงพูด และคุมพีคของเสียงสุดท้าย |

ถ้าคำสั่งไหนฟ้องว่าไม่พบโปรแกรม (ffmpeg, yt-dlp ฯลฯ) ให้ใช้ skill `tad-clip-setup` ตรวจและซ่อมก่อน

## ส่วน A. สร้างและดูแลคลังของผู้ใช้

1. หาโฟลเดอร์คลัง ดู `library_dir` ใน `config.json` ของ kit (ค่าเริ่ม `~/.tad-clip/config.json` · ถ้าตั้ง `TAD_CLIP_HOME` ไว้ ให้พิมพ์ `echo "$TC_HOME"` ในบล็อกที่ขึ้นต้นด้วยท่อนเริ่มต้นเพื่อดูโฟลเดอร์จริง) ถ้าว่าง ถามผู้ใช้ว่ามีโฟลเดอร์มีม/เสียงอยู่ที่ไหน ถ้ายังไม่มี แนะนำให้สร้างโฟลเดอร์ว่างแล้วเก็บของที่เจอระหว่างทำคลิปลงไป · ตั้งค่าโดยแก้เฉพาะ key `library_dir` ในไฟล์นั้น (ใช้ Edit ห้ามเขียนทับทั้งไฟล์)
2. สแกน

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   "$NODE" engine/library.mjs index --dir "<path เต็มของโฟลเดอร์คลัง>"
   ```

   อ่านเฉพาะ `.mp4 .mov .gif .webp .png .jpg .mp3 .wav .m4a` แล้วเขียน `.tad-clip/catalog.jsonl` ในโฟลเดอร์นั้น (id มีม `m001` เสียง `s001`) · รันซ้ำได้ id ไม่เปลี่ยน ของที่แท็กไว้ไม่หาย · ย้ายไฟล์ไปโฟลเดอร์อื่นโดยชื่อเดิม id ตามไป · เปลี่ยนชื่อไฟล์ = ได้ id ใหม่ (โน้ตเดิมไม่ตามไป)
3. ดูภาพรวมทีละหน้า (24 ช่อง เลข id อยู่มุมซ้ายบน)

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   "$NODE" engine/library.mjs sheet --untagged --page 1
   ```

   เปิดไฟล์ JPG ที่มันพิมพ์ path ออกมา (Read รูป) ดูให้ครบทุกช่อง แล้วแท็กทีละตัว
4. แท็ก

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   "$NODE" engine/library.mjs tag m012 --tags "ตกใจ,เงินหาย,ช็อก" --emotion ช็อก --beat reaction --risk safe --note "ใช้ตอนเจอตัวเลขที่ไม่คาดคิด · ช่วงเด็ด 0.4-1.6 วินาที"
   ```

   - `--tags` 2-5 คำที่ผู้ใช้จะพิมพ์ค้น เขียนเป็นความรู้สึกหรือสถานการณ์ ("ตกใจ" "เถียงไม่ฟัง" "เงินหาย") ไม่เขียนบรรยายภาพ ("ผู้ชายใส่สูท")
   - `--beat` เลือก 1-2 ตัวจาก hook · pain · twist · punchline · reaction · transition · cta · outro (คั่นด้วย `,`)
   - `--risk`: `safe` = ท่าทางหรือภาพทั่วไป · `caution` = มาจากหนัง ทีวี เพลง หรือมีโลโก้/คนดังชัด (ใช้โพสต์ปกติได้ แต่ไม่เอาไปยิงแอด) · `avoid` = ผู้ใช้สั่งห้ามใช้ หรือล้อเลียนกลุ่มคน การเมือง ศาสนา ความรุนแรง
   - `--note` 1 ประโยคว่าใช้ตอนไหนถึงตลก · คลิปยาวเกิน 5 วินาทีให้เขียนช่วงเด็ดเป็นวินาทีด้วย
   - `--favorite yes` เมื่อผู้ใช้บอกว่าชอบตัวนี้ · `--risk avoid` เมื่อผู้ใช้บอกว่าอย่าใช้อีก
   - ดูภาพแล้วไม่รู้ว่ามุกคืออะไร ให้ถามผู้ใช้ ห้ามเดา · ตัวที่ยังไม่แท็กยังค้นเจอจากชื่อไฟล์ แต่จะอยู่ท้ายผลเสมอ (ไม่มีแท็กให้จับคู่กับประโยค) จึงควรแท็กให้ครบก่อนใช้งานจริง
   - ผู้ใช้สอนหรือแก้อะไรเมื่อไหร่ รัน `tag` ทับทันที ค่าล่าสุดที่ผู้ใช้บอกคือค่าที่ใช้
5. เสียงเอฟเฟกต์: Claude ฟังเสียงไม่ได้ ให้ใช้ชื่อไฟล์ กับความยาวจากคำสั่ง `sounds` · ถ้าในเสียงมีคนพูด ถอดข้อความด้วย `engine.asr` แล้วแท็กตามคำที่ได้ยิน · เสียงที่ชื่อกับข้อความไม่บอกอะไร (เช่น `sound-17.mp3`) ให้ผู้ใช้บอกว่าเป็นเสียงอะไร หรือปล่อยไม่แท็ก ห้ามแต่งว่าเป็นเสียงอะไร

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   "$NODE" engine/library.mjs sounds --limit 50
   "$PY" -m engine.asr transcribe "<path เต็มของไฟล์เสียง>" --out "$TC_HOME/cache/<ชื่อ>.json"
   ```
6. ทำครบหน้าแล้วสรุปผู้ใช้ 3 บรรทัด: แท็กกี่ตัว ข้ามกี่ตัว มีอะไรต้องถาม แล้วไปหน้าถัดไป (`--page 2`) จนไม่เหลือ ดูสถานะรวมด้วยคำสั่ง `stats` ของ `engine/library.mjs`

ขอบเขต: เขียนได้เฉพาะโฟลเดอร์ `.tad-clip/` ในคลัง ไม่ย้าย ไม่ลบ ไม่เปลี่ยนชื่อไฟล์ของผู้ใช้

## ส่วน B. เลือกมีมและเสียงจากคลังไปใส่คลิป

1. แตกบท (หรือ `phrases.json`) เป็นจังหวะ: hook · pain · twist · punchline · reaction · cta
2. จำนวน: 2-4 ตัวต่อคลิป 60 วินาที (ราว 3) · ถ้าผู้ใช้ขอแบบ "ปั่นๆ" 5-8 ตัว · วางตรงจุดที่มีมทำงานแทนคำพูดได้ (ปล่อยมุก รีแอ็กชันต่อตัวเลขที่ช็อก หักมุม) · ห้ามทับประโยคที่เป็นหลักฐาน (ตัวเลข ขั้นตอน ชื่อเครื่องมือ ภาพจริงที่กำลังโชว์) เพราะมีมแย่งสายตา คนดูจะพลาดของ · ห้ามวางมีมที่ต้องรู้บริบทก่อนถึงจะเก็ตไว้ 2 วินาทีแรก
3. ค้นทีละจังหวะ อย่างน้อย 2 มุมต่อจังหวะ คือความหมายของประโยค และทรงมุก ("ทำเป็นไม่เป็นไรทั้งที่พัง")

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   "$NODE" engine/library.mjs search --q "เงิน ตกใจ" --beat punchline --limit 8
   "$NODE" engine/library.mjs search --emotion ช็อก --beat reaction --kind gif
   "$NODE" engine/library.mjs sounds --q "บูม" --beat reaction
   "$NODE" engine/library.mjs show m012
   ```

   - คำค้นหลายคำคั่นด้วยเว้นวรรค ตรงมากคำยิ่งขึ้นก่อน · คำที่ตรงกับโน้ตและแท็กมีน้ำหนักมากกว่าตรงกับชื่อไฟล์ · ตัวที่แท็กแล้วขึ้นก่อนตัวที่ยังไม่แท็ก และตัวโปรดขึ้นก่อนเมื่อสูสี
   - ค่าเริ่ม = `safe` + `caution` · `avoid` ไม่ถูกเสนอ ยกเว้นผู้ใช้เอ่ยชื่อมีมนั้นเอง
   - เมื่อสูสี เลือกตัวที่คนดูกลุ่มเป้าหมายของผู้ใช้รู้จักก่อน
4. ภาพอย่างเดียว ไม่เอาเสียงของมีมติดมา (เสียงเอฟเฟกต์วางแยกด้านล่าง) ยาว 1.5-2.5 วินาที · วางเป็นช็อตแบบ split (มีมครึ่งบน หน้าคนพูดอยู่ครึ่งล่าง) ตามวิธีใน skill `tad-clip-visual` และติดป้ายแหล่งที่มา `source` ทุกครั้ง
5. มีมที่เป็นคลิปยาว ห้ามเสนอทั้งคลิป ต้องระบุช่วงวินาที: ใช้ช่วงที่โน้ตเขียนไว้ ถ้าไม่มี ดึงเฟรมดูหรือถอดเสียงหาประโยคที่ตรง แล้วเขียนว่า "ช่วงที่ Claude เดา ตรวจก่อนตัด"
6. GIF ต้องแปลงเป็น mp4 ก่อนใส่ (1080×960 ภาพเต็มสัดส่วนวางบนพื้นเบลอของตัวเอง วนจนยาวอย่างน้อย 2 วินาที ไม่มีเสียง)

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$PY" -m engine.fetch gif2clip "<path เต็มของไฟล์.gif>" "$W/assets/memes/<ชื่อ>.mp4"
   ```

   ภาพนิ่งใช้ได้เลย · มีมวิดีโอตัดช่วงด้วย `"$FF"` แล้วเก็บใน `$W/assets/memes/`

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$FF" -ss <เริ่ม> -t <ยาว> -i "<path เต็มของไฟล์>" "$W/assets/memes/<ชื่อ>.mp4"
   ```
7. copy ไฟล์ที่เลือกเข้า `$W/assets/memes/` ไม่ชี้ไฟล์ในคลังตรงๆ (คลังอาจย้ายที่) แล้วจดลง CREDITS (หัวข้อ C4) ด้วย `--license "มีมจากคลังของผู้ใช้ (ไม่ทราบเจ้าของ)" --ads no`
8. ส่งชีตให้ผู้ใช้:

   | # | ตรงไหน (ประโยค / วินาที) | จังหวะ | มีม (id + ไฟล์) | ช่วงที่ใช้ | เสียง | ทำไมเข้า |
   |---|---|---|---|---|---|---|

   ทุก id path ช่วงเวลา ต้องมาจากผลคำสั่งจริง · ไม่มีมีมที่เข้าจริงให้บอกตรงๆ ว่าคลังขาดอะไร ดีกว่ายัดตัวที่ไม่เข้า

### เสียงเอฟเฟกต์

เขียน `$W/sfx.json` วางเสียงตรงมุกหรือรีแอ็กชัน ไม่ทับคำสำคัญ

```json
[
  {"file": "boom.mp3", "at": 12.4, "dur": 1.0, "why": "มุกตอนพูดว่ายอดหาย"},
  {"file": "sfx/ding.wav", "at": 31.0, "db": -10}
]
```

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
"$PY" -m engine.sfx_mix "$W/out/preview-composite-subs.mp4" "$W/sfx.json" "$W/final.mp4"
```

ไม่มีเอฟเฟกต์ก็ต้องรันคำสั่งนี้ โดยเขียน `$W/sfx.json` เป็น `[]` เพราะ `engine.sfx_mix` คือที่เดียวที่คุมพีคของเสียงสุดท้าย (limiter เพดาน 0.89 ให้ผ่านเกณฑ์ true peak ของ `doctor --qc`) ห้ามใช้ `cp` หรือ copy ไฟล์ข้ามไป

- `file` แบบ relative หาข้างไฟล์ `sfx.json` ก่อน แล้วค่อยหาใน `library_dir` · `at` = วินาทีที่เริ่มเล่น · `dur` = ตัดให้สั้นลงแล้วเฟดท้าย 0.15 วินาที
- `db` ค่าเริ่ม -8 หมายถึงเบากว่าเสียงพูด ณ จังหวะนั้น 8 dB · เครื่องวัดเองทุกเสียง เพราะไฟล์เสียงดังไม่เท่ากัน ต่างกันได้ 25 dB ขึ้นไป ห้ามตั้งความดังเอง
- เสียงพูดไม่ถูกปรับความดัง ภาพไม่ถูกเข้ารหัสใหม่ (เสียงถูกเข้ารหัสใหม่เป็น AAC หลังผ่าน limiter) · ถ้าเอฟเฟกต์ตกช่วงที่คนไม่ได้พูด ใช้ระดับเสียงพูดทั้งคลิปเป็นตัวอ้างอิงแทน · เอฟเฟกต์โมโนบนเสียงพูดสเตอริโอ (หรือกลับกัน) ถูกวัดและปรับให้ได้ −8 dB ต่อช่องเท่ากัน
- รันซ้ำแล้ว `final.mp4` ใหม่กว่า `sfx.json` กับต้นทางทุกไฟล์ จะข้าม · แก้ `sfx.json` แล้วรันใหม่ได้เลย · อยากมิกซ์ใหม่ทั้งที่ไม่มีอะไรเปลี่ยน ใส่ `--force`
- เสียงที่หามาจากเน็ตต้องจด CREDITS เหมือนภาพ

### C1. ถามผู้ใช้ 2 ข้อก่อนหาอะไรทั้งนั้น

ถ้า `tad-clip` ถามไปแล้วในขั้นถามตอนเริ่มของมัน ใช้คำตอบเดิม ไม่ถามซ้ำ ถ้ายังไม่ได้ถาม ใช้ AskUserQuestion ถาม 2 ข้อพร้อมกัน

1. เอาอะไรมาแทรกบ้าง (เลือกได้หลายข้อ): ภาพจริง/หลักฐาน · คลิปจริง · มีม · เสียงเอฟเฟกต์ — การ์ดข้อความ/กราฟิกทำให้เสมออยู่แล้ว ไม่ต้องถาม จึงไม่อยู่ในตัวเลือก (AskUserQuestion รับตัวเลือกได้ไม่เกิน 4 ข้อ · ชุดนี้ตรงกับขั้นถามตอนเริ่มของ `tad-clip` ทุกตัวอักษร)
2. เอามาจากไหน: "ให้ Claude หาจากเน็ตให้" · "ผมมีไฟล์เอง (บอกโฟลเดอร์)" · "ผสมกัน"

หลังได้คำตอบ

- ไฟล์ของผู้ใช้เอง: ขอ path เต็มของโฟลเดอร์ แล้วสแกนและค้นด้วย `--dir` ตามบล็อกข้างล่าง (โฟลเดอร์ชั่วคราวไม่ต้องบันทึกเป็น `library_dir` ถ้าผู้ใช้ไม่ขอ) · ของผู้ใช้ถ่ายเองจดเป็น `--url -` `--license "ถ่ายเอง"` `--ads yes`
- ผสมกัน: ใช้ของที่ผู้ใช้มีก่อน ส่วนที่ขาดค่อยหาจากเน็ต
- ผู้ใช้พิมพ์ว่า "หาให้เลยไม่ต้องถาม" หรือความหมายเดียวกัน = ข้ามการเสนอรายการก่อนโหลด (หัวข้อ C3) เฉพาะรอบนี้ ไม่จำข้ามคลิป

```bash
"$NODE" engine/library.mjs index --dir "<path เต็มของโฟลเดอร์ผู้ใช้>"
"$NODE" engine/library.mjs search --dir "<path เต็มของโฟลเดอร์ผู้ใช้>" --q "<คำค้น>"
```

### C2. ลำดับแหล่ง (หาจากเน็ต)

ไล่ตามลำดับ แหล่ง ก → ข → ค เจอของที่ใช้ได้ในแหล่งก่อนแล้ว ไม่ต้องลงไปแหล่งถัดไป

- แหล่ง ก ไลเซนส์ฟรี: Pexels · Pixabay · Wikimedia Commons (เฉพาะ CC0 / public domain / CC BY)
  - Commons: ค้นด้วยบล็อกข้างล่าง (`--type image` หรือ `--type video`) ได้ JSON มี `title` `file_url` `page_url` `license` `author` `ads_ok` `bytes` · ค้นเป็นคำอังกฤษได้ผลดีกว่าไทย · เลือกตัวที่ `ads_ok` เป็น true ก่อน · CC BY-SA ใช้โพสต์ปกติได้ แต่ลงธงยิงแอดว่า "ไม่" · ลิงก์ `upload.wikimedia.org` ที่ส่งให้ `image`/`video` ถูกเติมไลเซนส์และชื่อผู้ถ่ายจาก Commons ให้เอง

    ```bash
    K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
    "$PY" -m engine.fetch commons "<คำค้น>" --type image --limit 8
    ```

  - Pexels (ตรวจแล้วว่าใช้ได้ทั้งคลิปแนวนอนและแนวตั้ง):
    1. ค้นด้วย WebSearch โดยใส่พารามิเตอร์ `allowed_domains: ["pexels.com"]` กับคำค้นภาษาอังกฤษ · ห้ามพิมพ์ตัวดำเนินการ `site:` ไว้ในคำค้น (ผลที่ได้เป็นเว็บอื่นทั้งหมด) · Pixabay ใช้ `allowed_domains: ["pixabay.com"]` แบบเดียวกัน
    2. เปิดหน้าวิดีโอที่เลือกด้วย WebFetch เพื่ออ่านชื่อผู้ถ่าย ชื่อคลิป ความยาว แนวตั้งหรือแนวนอน · curl หรือสคริปต์เปิดหน้าค้นหา/หน้าวิดีโอของ Pexels และ Pixabay ไม่ได้ (ติด Cloudflare ได้ 403) จึงต้องใช้ WebFetch และต้องส่งชื่อผู้ถ่ายให้คำสั่งโหลดเองด้วย `--author`
    3. โหลดด้วย `video` โดยส่งลิงก์หน้าวิดีโอ หรือลิงก์ `https://www.pexels.com/download/video/<เลข>/` ก็ได้ · คำสั่งเติมขนาดให้เอง (ลองแนวนอน `h=1080&w=1920` ก่อน แล้วสลับ h/w สำหรับคลิปแนวตั้ง ไม่เกิน `--max-height`) ห้ามพิมพ์ลิงก์ดาวน์โหลดเปล่าๆ เอง เพราะ Pexels ตอบไฟล์ 4K กลับมา · ไลเซนส์ "Pexels License" และธงยิงแอด "ใช่" ถูกเติมให้เอง
    4. ภาพนิ่งของ Pexels ใช้ลิงก์ไฟล์ตรง `https://images.pexels.com/photos/<เลข>/pexels-photo-<เลข>.jpeg` (อ่านลิงก์ได้จากหน้ารูปด้วย WebFetch) ด้วย `image` · ตั้งชื่อไฟล์ให้ตรงเรื่องด้วย `--name`

    ```bash
    K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
    W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
    "$PY" -m engine.fetch video "https://www.pexels.com/video/<ชื่อ>-<เลข>/" --out "$W/assets/footage" --start 0 --end 6 --author "<ชื่อผู้ถ่ายจากหน้าวิดีโอ>" --note "ใช้ตอนพูดถึง …"
    "$PY" -m engine.fetch image "https://images.pexels.com/photos/<เลข>/pexels-photo-<เลข>.jpeg" --out "$W/assets/proof" --name "<ชื่อไฟล์ที่ตรงเรื่อง>" --author "<ชื่อผู้ถ่าย>"
    ```

  - ถ้า `video` ตอบว่า "Pexels ไม่มีไฟล์ของวิดีโอ …" (เลขผิด วิดีโอถูกลบ หรือ Pexels เปลี่ยนวิธีดาวน์โหลด) ให้ผู้ใช้เปิดหน้าวิดีโอแล้วกดดาวน์โหลดเอง บอก path มา แล้วจดลง CREDITS ด้วย `credit` · Pixabay เปิดหน้าด้วยสคริปต์ไม่ได้เหมือนกัน แต่ลิงก์ไฟล์ตรง `cdn.pixabay.com/…` ที่อ่านได้จาก WebFetch โหลดด้วย `image` ได้ (ตรวจแล้วกับรูป · คลิปของ Pixabay ยังไม่ได้ตรวจ ถ้าไม่ผ่านให้ผู้ใช้กดโหลดเอง) · ไลเซนส์ "Pixabay Content License" ถูกเติมให้เอง
- แหล่ง ข หน้าทางการของแบรนด์หรือข่าว (หน้าประวัติบริษัท ข่าวประชาสัมพันธ์ รายงานประจำปี): ใช้แบบอ้างอิงประกอบเรื่องที่เล่า พร้อมป้ายแหล่งที่มาบนจอ (ชื่อแหล่ง + ปี) · ภาพบนหน้าทางการมักเป็นไฟล์เล็ก ให้โหลดชุดเต็มจากหน้าต้นทางเอง · โหลดรูปด้วยบล็อกข้างล่าง (`--name` ตั้งชื่อไฟล์ให้ตรงเรื่อง · เว็บที่ไม่ใช่ Pexels/Pixabay/Wikimedia ไม่มีไลเซนส์ให้เติมเอง ต้องระบุ `--license` ถ้าจะจดทันที)

  ```bash
  K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
  W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
  "$PY" -m engine.fetch image "<ลิงก์ไฟล์รูป>" --out "$W/assets/proof" --name "<ชื่อไฟล์ที่ตรงเรื่อง>"
  ```
- แหล่ง ค YouTube และคลิปมีม: ใช้เมื่อแหล่ง ก กับ ข ไม่มีของที่เล่าเรื่องนั้นได้
  - ค้นด้วย `ytsearch` (ได้ id ชื่อ ช่อง ความยาว ลิงก์ ยังไม่โหลดอะไร) เลือกช่องทางการก่อน · เรื่องต่างประเทศค้นด้วยภาษาของประเทศนั้นด้วย (ญี่ปุ่น: `<สินค้า> CM 1971` หรือ `<บริษัท> 公式`)
  - โหลดเฉพาะช่วงที่ใช้ ไม่เกิน 1080p ด้วย `video` (ไม่ใส่ `--start/--end` = โหลดทั้งคลิป ทำเฉพาะคลิปสั้น) · เติม `--no-audio` ถ้าไม่ใช้เสียง

    ```bash
    K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
    W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
    "$PY" -m engine.fetch ytsearch "<คำค้น>" --limit 8
    "$PY" -m engine.fetch video "<ลิงก์>" --out "$W/assets/footage" --start 12.5 --end 16
    ```

  - ธงยิงแอดของทุกชิ้นจากแหล่ง ค คือ "ไม่"

ในโหมด "หาให้เลยไม่ต้องถาม" (และโหมด "ทำรวดเดียว" ของ `tad-clip`) ใช้ได้เฉพาะแหล่ง ก กับ ข · แหล่ง ค ต้องเสนอรายการก่อนเสมอ เว้นแต่ผู้ใช้เอ่ยถึง YouTube หรือคลิปมีมจากเน็ตด้วยตัวเองว่าไม่ต้องถาม

มีมและคลิปจริงที่ต้องมาจากแหล่ง ค ในโหมดทำรวดเดียว โหลดโดยไม่ถามไม่ได้ ให้ทำตามลำดับนี้ (ผู้ใช้ขอมีมมาแล้ว จะข้ามเงียบๆ ไม่ได้ และจะเอาของที่ไม่เกี่ยวมาแทนก็ไม่ได้)

1. ถ้า `library_dir` ใน config ตั้งไว้และค้นคลังแล้วเจอมีมที่เข้ากับจังหวะ (ส่วน B) ใช้ของในคลังของผู้ใช้ จดธงยิงแอด "ไม่"
2. ถ้าไม่มีของในคลัง ห้ามเอารูปที่ไม่ใช่มีมจริง (รูปปั้น ภาพวาดเก่า คลิปอาร์ต ภาพสต็อกสีหน้า) มาใช้แทนมีม ให้ค้นผู้สมัคร 3-5 ตัวด้วย `ytsearch` (ยังไม่โหลด) แล้วเขียนตาราง ลิงก์ · ช่อง · จะวางตรงประโยคหรือวินาทีไหน · ทำไมเข้า ใส่ในข้อความส่งงาน และเก็บไว้ใน `$W/meme-candidates.md` ให้ผู้ใช้อนุมัติทีหลัง (อนุมัติแล้วค่อยโหลดด้วย `video` ตามแหล่ง ค)
3. จังหวะที่ยังไม่มีมีม ใช้การ์ดมุก หรือการ์ดข้อความแบบคีย์เวิร์ดป๊อปตาม skill `tad-clip-visual` เติมจังหวะนั้นแทน ไม่ปล่อยว่าง และบอกผู้ใช้ในข้อความส่งงานว่าจังหวะไหนรอมีมจริง

กติการ่วมของทุกแหล่ง

- ห้ามเสนอหรือใช้ลิงก์ที่ยังไม่ได้เปิดดูจริง
- เจอหน้าที่ต้องล็อกอิน ติดระบบกันบอท หรือติด paywall ให้หยุด บอกผู้ใช้ ให้ผู้ใช้โหลดเอง · ห้ามหาทางข้าม
- ตัวเลือกที่หาไม่เจอไลเซนส์ ถือว่าไลเซนส์ไม่ชัด ลงธงยิงแอด "ไม่" และบอกผู้ใช้

### C3. เสนอรายการก่อนโหลด

ก่อนโหลดอะไรลงเครื่อง ส่งตารางให้ผู้ใช้เลือก (AskUserQuestion เลือกหลายข้อ หรือให้ตอบเป็นเลขข้อ)

| # | อะไร | ลิงก์ | ใช้ตรงไหนของคลิป | ไลเซนส์ | ใช้ยิงแอดได้ | ขนาด / ความยาว |
|---|---|---|---|---|---|---|

ห้ามโหลดก่อนได้คำตอบ ยกเว้นโหมด "หาให้เลยไม่ต้องถาม" ซึ่งโหลดเลยแล้วสรุปรายการทั้งหมดที่ใช้พร้อมธงยิงแอดในข้อความส่งงาน

### C4. จดทุกชิ้นลง CREDITS.md

หลังโหลดหรือ copy เสร็จทุกชิ้น จดทันที ไฟล์อยู่ที่ `$W/CREDITS.md` (สร้างหัวตารางให้เองครั้งแรก จดซ้ำชิ้นเดิมจะแก้แถวเดิม ไม่เพิ่มแถวซ้ำ)

เฉพาะ session หลักเท่านั้นที่เขียน `$W/CREDITS.md` ห้าม subagent เขียนไฟล์นี้ (ตัวตรวจข้อเท็จจริงและตัวหาของรันพร้อมกัน) · subagent คืนผลเป็นข้อความตารางให้ session หลัก แล้ว session หลักจดทีละแถวหลัง subagent ทุกตัวจบ ใส่ข้อความนี้ใน prompt ของ subagent ได้เลย: "ห้ามเขียนหรือแก้ CREDITS.md · ตอนจบคืนตารางเป็นข้อความ: ของที่โหลด = บรรทัด `จด:` ที่คำสั่งโหลดพิมพ์ออกมา · ข้อเท็จจริง = คอลัมน์ ข้อความบนจอ | แหล่ง | ปี | ลิงก์ | หมายเหตุ" · คำสั่งเขียนไฟล์มี lock กันชนกันไว้แล้ว แต่ไม่ใช่เหตุผลให้ subagent เขียนเอง · ตัวเลือก `--credit-file` ของ `video` กับ `image` ให้ใช้เฉพาะ session หลักที่โหลดเอง (subagent ไม่ใส่ จะได้บรรทัด `จด:` คืนมาแทน)

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
"$PY" -m engine.fetch credit --file "$W/CREDITS.md" --item "<ชื่อไฟล์หรือสิ่งที่เห็นในภาพ>" --url "<ลิงก์ที่มา · ของที่ผู้ใช้ถ่ายเองใส่ ->" --license "<ไลเซนส์>" --ads yes --note "<ชื่อผู้ถ่าย · ใช้ตรงวินาทีไหน>"
```

ธง `--ads` ตอบ "ใช้ยิงแอดได้ไหม" ตามตารางนี้ ไม่แน่ใจให้ตอบ `no`

| ที่มา | ใช้ยิงแอดได้ |
|---|---|
| ผู้ใช้ถ่ายหรือทำเอง | ใช่ |
| CC0 · public domain · CC BY (ใส่ชื่อเจ้าของตามที่ไลเซนส์กำหนด) | ใช่ |
| Pexels · Pixabay | ใช่ (ภาพที่เห็นหน้าคนชัด อย่าทำให้ดูเหมือนเขาเชียร์สินค้า · มีโลโก้แบรนด์ในภาพ ถือว่าไม่แน่ใจ) |
| CC BY-SA · GFDL | ไม่ (โพสต์ปกติได้พร้อมเครดิต) |
| หน้าทางการของแบรนด์ · ภาพข่าว | ไม่ |
| คลิป YouTube ของคนอื่น · หนัง · ทีวี · มีม · เพลง | ไม่ |
| ไลเซนส์ไม่ชัดหรือหาไม่เจอ | ไม่ |

ตารางตรวจข้อเท็จจริงอยู่ในไฟล์เดียวกัน ใต้ตารางของที่ใช้ ใต้หัวข้อ "ตรวจข้อเท็จจริง" หัวตารางคือ

`| ข้อความบนจอ | แหล่ง | ปี | ลิงก์ | หมายเหตุ |`

จดทีละแถวด้วย `fact` (ข้อความเดิมจดซ้ำจะแก้แถวเดิม) · `credits-summary` นับเฉพาะตารางของที่ใช้ ไม่นับตารางนี้

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
"$PY" -m engine.fetch fact --file "$W/CREDITS.md" --text "<ข้อความหรือตัวเลขที่ขึ้นบนจอ>" --source "<ชื่อแหล่ง>" --year "<ปีของแหล่ง>" --url "<ลิงก์ หรือ ->" --note "<ตรวจแล้ว: ถูก / ถูกบางส่วน / ผิด · ต้องแก้อะไร>"
```

ตอนส่งงาน สรุปผลด้วยบล็อกข้างล่าง (บอกกี่ชิ้น ชิ้นไหนห้ามยิงแอด)

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
"$PY" -m engine.fetch credits-summary --file "$W/CREDITS.md"
```

### C5. อธิบายลิขสิทธิ์ให้ผู้ใช้ฟัง

เมื่อผู้ใช้ถามว่าทำไมต้องแยก หรือเมื่อมีของที่ติดธง "ไม่" ในคลิปที่ผู้ใช้จะโปรโมต อธิบายประมาณนี้ (ภาษาง่าย ไม่ต้องยกกฎหมาย)

- โพสต์ปกติลงเพจหรือช่องของตัวเอง: คลิปหนัง ทีวี ข่าว มีม ยังเป็นของเจ้าของ การหยิบท่อนสั้นมาประกอบเรื่องที่เราเล่า พร้อมบอกที่มา เป็นสิ่งที่ครีเอเตอร์ทำกันทั่วไป ผลที่เจอบ่อยคือโดนแจ้งลบ ปิดเสียง หรือเจ้าของเคลมรายได้ เจ้าของสั่งให้ถอดได้เสมอ
- ยิงแอดคือจ่ายเงินให้แพลตฟอร์มดันคลิปที่มีงานของคนอื่นอยู่ข้างใน เพื่อขายของ เจ้าของมองว่าเรากำลังหากำไรจากงานเขา และระบบตรวจโฆษณาเข้มกว่าโพสต์ปกติ คลิปอาจไม่ผ่านการอนุมัติ และบัญชีโฆษณาเสี่ยงโดนเตือนหรือระงับ
- ธง "ใช้ยิงแอดได้: ไม่" ในไฟล์ CREDITS.md หมายความว่า ถ้าจะโปรโมตคลิปนี้ ต้องเปลี่ยนชิ้นนั้นก่อน เช่น ใช้ภาพจาก Pexels หรือ Pixabay หรือถ่ายเอง · ผู้ใช้เป็นคนตัดสินใจ Claude มีหน้าที่ติดป้ายให้ชัด
- ปิดท้ายทุกครั้งว่านี่เป็นหลักทั่วไป ไม่ใช่คำแนะนำทางกฎหมาย ถ้าเป็นงานใหญ่หรือมีเงินโปรโมตสูง ให้ขออนุญาตเจ้าของหรือปรึกษาทนาย

### C6. ตัวเลข คำพูด และป้ายกำกับ

- ตัวเลข ชื่อ ปี และคำพูดที่ขึ้นบนจอ หรือที่ผู้พูดอ้างในคลิป ต้องมีแหล่ง หาจากเอกสารต้นทาง (หน้าทางการ รายงานประจำปี สถิติหน่วยงาน) ไม่ใช่จากความจำของ Claude
- ขึ้นป้ายแหล่งที่มา "ชื่อแหล่ง + ปี" กำกับทุกตัวเลขบนจอ
- ห้ามแต่งตัวเลข ห้ามปัดให้สวย ยืนยันไม่ได้ให้ตัดออก หรือถามผู้ใช้ ห้ามปล่อยผ่าน
- ผู้พูดอ้างอะไรที่ผิดจากแหล่ง บอกผู้ใช้ตรงๆ ก่อนทำต่อ
- คำพูดของคนอื่นต้องเป็นคำพูดจริง และบอกว่าใครพูด
- ภาพ แอนิเมชัน หรือฟุตเทจสต็อกที่ใช้แทนเหตุการณ์ที่ไม่มีใครถ่ายไว้ ต้องติดป้าย "ภาพจำลอง" บนจอทุกช็อตที่ใช้ พร้อมแหล่งที่มา
- ห้ามใช้คลิปที่มีลายน้ำ หรือเลขเวลา (timecode) ฝังในภาพ เช่นพรีวิวของคลังฟุตเทจเสียเงิน เจอแล้วทิ้ง หาตัวอื่น

### C7. เตรียมคลิปก่อนวางใน plan

ทุกข้อในหัวข้อนี้ทำกับไฟล์ที่ copy ไว้ใน `$W/assets/footage/` ไม่แก้ไฟล์ต้นทาง

1. ทำภาพรวมของคลิป แล้วเปิดดูเอง หาลายน้ำ เลขเวลา ซับที่ฝังมา โลโก้ และจุดเริ่มที่ไม่ติดรอยตัดของต้นทาง · ชื่อไฟล์ไม่ซ้ำต่อคลิป (`<ชื่อคลิป>-sheet.jpg` วางข้างคลิป) · จำนวนช่องตามความยาวคลิป ช่องละ 0.5 วินาที สูงสุด 24 ช่อง (คลิป 6 วินาทีได้ 12 ช่อง ไม่เหลือที่ว่างสีดำ) มีเวลากำกับมุมซ้ายบนของทุกช่อง

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$PY" -m engine.fetch sheet "$W/assets/footage/<ชื่อคลิป>.mp4"
   ```

2. หารอยตัดฉากของต้นทาง แล้วเลือกจุดเริ่มหลังรอยตัด ไม่ให้ติดภาพช็อตถัดไป · ถ้าไม่มีรอยตัด คำสั่งพิมพ์ "ไม่พบจุดตัดฉาก" ชัดๆ (เริ่มที่วินาทีไหนก็ได้) ไม่ใช่เงียบเฉยๆ

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$PY" -m engine.fetch scenes "$W/assets/footage/<ชื่อคลิป>.mp4"
   ```

3. ครอปตัวหนังสือที่ฝังมา (ซับต้นทาง เนื้อเพลง ขอบดำ) ก่อนใส่ ไม่งั้นโผล่ข้างป้ายของเรา · ครอปแล้วภาพเหลือเล็กจนไม่คม ให้หาคลิปอื่น

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$FF" -i "<path เต็มของคลิป>" -vf "crop=w:h:x:y" -c:a copy "$W/assets/footage/<ชื่อ>-crop.mp4"
   ```

4. ต้นทางสั้นกว่าช็อตที่วาง: ยืดเฉพาะส่วนที่ใช้ (ตัวอย่างนี้ช้าลง 1.5 เท่า)

   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อวิดีโอไม่มีนามสกุล>"   # ใส่ path จริงทุกครั้ง
   "$FF" -i "<path เต็มของคลิป>" -vf "setpts=(PTS-STARTPTS)*1.5" -an "$W/assets/footage/<ชื่อ>-slow.mp4"
   ```

5. ภาพเทียบสองฝั่ง (ก่อน/หลัง · ประเทศ A กับ B): วางซ้าย-ขวาด้วย `hstack` ฝั่งละ 540×960 ไม่ซ้อนบน-ล่าง เพราะแถบกว้าง 2.25:1 ตัดหน้าหรือของในมือทิ้ง

## ห้ามทำ

- ห้ามโหลดอะไรก่อนผู้ใช้เลือกรายการ (ยกเว้นโหมด "หาให้เลยไม่ต้องถาม" ตามขอบเขตข้างบน)
- ห้ามแต่ง id ลิงก์ ไลเซนส์ หรือช่วงวินาที ทุกอย่างต้องมาจากผลคำสั่งจริงหรือหน้าที่เปิดดูจริง
- ห้ามเขียน ย้าย ลบ ไฟล์ในโฟลเดอร์คลังของผู้ใช้ นอกจาก `.tad-clip/`
- ห้ามเอาของที่ติดธงยิงแอด "ไม่" ไปบอกผู้ใช้ว่ายิงแอดได้
- ห้ามข้ามการจด CREDITS แม้จะเป็นของชิ้นเดียว
- ห้าม subagent เขียน `$W/CREDITS.md` คืนเป็นข้อความให้ session หลักจด
- ห้ามเอารูปปั้น ภาพวาดเก่า หรือคลิปอาร์ตมาใช้แทนมีม ไม่มีมีมจริงให้ทำตามหัวข้อ C2 (รายการผู้สมัคร + การ์ดมุก)
