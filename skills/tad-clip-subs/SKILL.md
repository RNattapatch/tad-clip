# ทำซับให้คลิป (tad-clip-subs)

ผู้ใช้ส่งคลิปที่ตัดแล้วมา คุณทำให้เป็นซับไทยที่อ่านทัน ตรวจคำที่ฟังผิดด้วยตัวเองใน session นี้ แล้วฝังลงวิดีโอ
พูดกับผู้ใช้เป็นภาษาไทย สั้น ตรง · ผู้ใช้ไม่ต้องรู้ว่าข้างใต้ใช้อะไร

## วิธีเรียกคำสั่ง (อ่านก่อนรันอะไร)

เครื่องมือ Bash ไม่จำตัวแปรข้ามคำสั่ง **ทุก block คำสั่งในไฟล์นี้จึงขึ้นต้นด้วยบรรทัดนี้เสมอ** (macOS ใช้ได้เลย · Windows ใช้ใน Git Bash ของ Claude Code):

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
```

ถ้า `${CLAUDE_PLUGIN_ROOT}` ไม่ถูกแทนค่า ให้ใช้ `~/.tad-clip/kit` (บรรทัดข้างบนทำให้เองแล้ว) บรรทัดนี้ตั้ง `KIT` (ที่ตั้งชุดเครื่องมือ) `TC_HOME` `PY` (python ของชุดเครื่องมือ: macOS `~/.tad-clip/venv/bin/python` · Windows `%USERPROFILE%\.tad-clip\venv\Scripts\python.exe`) `FF` (ffmpeg ที่มีตัวฝังซับ) `NODE` และ **`cd` เข้าโฟลเดอร์ชุดเครื่องมือให้** โค้ดอยู่ที่ `${CLAUDE_PLUGIN_ROOT}/engine/...` ทุกคำสั่งจึงเรียกด้วย `"$PY" -m engine.subs ...`

เพราะ `cd` ไปแล้ว **path ของไฟล์ผู้ใช้ต้องเป็น path เต็มเสมอ** และครอบด้วย `"..."` (ชื่อไทยและช่องว่างใช้ได้ เช่น `"/Users/สมชาย/คลิป ทดสอบ 1.mp4"`)
ถ้าบรรทัดแรกขึ้นว่า tad-clip ยังไม่ได้ติดตั้ง หรือคำสั่งบอกว่าขาดโปรแกรม/โมเดล ให้บอกผู้ใช้ว่า "พิมพ์ \"ตรวจเครื่อง tad-clip\"" แล้วหยุด อย่าติดตั้งเอง

**โฟลเดอร์งาน** ใส่ไว้บรรทัดที่สองของ block ที่ต้องใช้ ทุกครั้งแทน `<...>` ด้วย path จริงของคลิปนี้ (ห้ามปล่อยค้าง):

- คลิปมาจาก skill tad-clip → ใช้โฟลเดอร์งานเดิม `<โฟลเดอร์ของวิดีโอ>/tad-clip-<ชื่อไฟล์วิดีโอไม่มีนามสกุล>` (คลิปที่ตัดแล้วคือ `$W/roughcut.mp4`)
- คลิปเดี่ยวๆ ที่ผู้ใช้ส่งมา → สร้างโฟลเดอร์ชื่อเดียวกันนี้ข้างคลิป (`mkdir -p "$W"`)

ไฟล์ซับทั้งหมดอยู่ใน `$W/subs`

## ขั้นตอน

### 1. ถอดเสียงและตัดเป็นซับดิบ

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
V="<path เต็มของคลิป>"
mkdir -p "$W"
"$PY" -m engine.subs "$V" -o "$W/subs" --karaoke
```

- ครั้งแรกถอดเสียงนานกว่าความยาวคลิปหลายเท่า (CPU) บอกผู้ใช้ก่อน
- ได้ใน `$W/subs`: `audio.wav` · `asr.json` · `raw.cues.json` · `raw.srt` · **`review.md`**
- รันซ้ำได้ปลอดภัย: ขั้นที่ทำแล้วจะข้าม (ใช้ `--force` เมื่ออยากถอดใหม่ทั้งหมด) และไม่แตะ `edits.json` ของผู้ใช้
- เติม `--max-chars N` (ค่าเริ่มต้น 22 ตัวอักษรต่อบรรทัด) แล้วรันซ้ำ = ตัดซับดิบใหม่โดยไม่ถอดเสียงซ้ำ

### 2. อ่าน `$W/subs/review.md` ทั้งไฟล์

หัวไฟล์บอกกติกาและรูปแบบ `edits.json` พร้อมตัวอย่างครบแล้ว ไม่ต้องเปิดไฟล์อื่น
ถัดมาคือ Flags และรายการ cue ทุกบรรทัด (เลข เวลา ข้อความ ธง)

| ธง | แปลว่า |
|---|---|
| `ASR STALL` | คำเดียวค้างเกิน 2.5 วินาที เสียงช่วงนั้นมักหายทั้งท่อน |
| `GAP` | ช่องว่างระหว่าง cue เกิน 2 วินาที บอกระดับเสียงช่วงนั้นด้วย (ดัง = น่าจะมีคำพูดหาย · เงียบ = ปกติ) |
| `GLOSSARY` | cue มีคำในคลังคำ หรือถูกแก้อัตโนมัติ เช็คว่าสะกดถูก |

คุณฟังเสียงไม่ได้ ตัดสินจากข้อความ บริบทบรรทัดก่อนหลัง และตัวเลขในธงเท่านั้น

### 3. เขียน `$W/subs/edits.json` (เฉพาะจุดที่ฟังผิดชัดเจน)

บันทึกไว้ข้าง `review.md` ใช้ key `corrections` · `resplit` · `drop` · `flags` · `notes` ตามตัวอย่างหัว `review.md` (schema เต็มที่ `${CLAUDE_PLUGIN_ROOT}/engine/subs/edits.schema.json`)

**กฎ: ห้ามแก้เกินจำเป็น**
- แก้เฉพาะ: ชื่อหรือศัพท์ที่ถอดเพี้ยน · คำไทยสะกดผิดจนอ่านสะดุด · อังกฤษที่ถอดเป็นคำอ่านไทย (เช่น "คอร์ทโค้ด" → "Claude Code")
- ห้ามเกลาสำนวน ห้ามทำให้สุภาพ ห้ามตัดคำพูดติดปาก (ครับ นะ เนี่ย) ห้ามเติมคำที่ไม่ได้พูด ซับคือคำพูดจริง
- ไม่มั่นใจ = ใส่ใน `flags` ไม่แก้ · ไม่มีอะไรผิดชัดเจน = ไม่ต้องเขียน `edits.json` เลย
- `from` ต้องตรงกับบรรทัดเดิมทุกตัวอักษร เลข `i` ใช้เลขใน `review.md` เสมอ
- ย้ายรอยตัดบรรทัดที่ตัดกลางคำ/กลางวลี (เช่น "มองโบร / ชัวร์") ใช้ `resplit` · cue ที่ซ้ำกับตัวอักษรที่ฝังบนจออยู่แล้วใช้ `drop`
- เครื่องไม่รับ edits ที่แตะเกินครึ่งของ cue (exit 3) นั่นแปลว่าถอดเสียงผิดทั้งคลิป ให้ถอดใหม่ ไม่ใช่แก้ทีละคำ

### 4. ออกไฟล์สุดท้าย

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
"$PY" -m engine.subs finalize "$W/subs"
```

ได้ `<ชื่อคลิป>.srt` · `.ass` · `.karaoke.ass` · `.lrc` · `cues.json` และ `edits-report.md` (แก้อะไร สงสัยอะไร โค้ดตีกลับอะไร) ใน `$W/subs` (ถ้า `$W/subs/edits.json` มีอยู่จะถูกใช้เอง ใส่ `--edits <path เต็ม>` เมื่อไฟล์อยู่ที่อื่น)
อ่าน `edits-report.md` ถ้ามีรายการถูกตีกลับ (ส่วนใหญ่ `from` ไม่ตรง) แก้ `edits.json` แล้วรัน finalize ซ้ำได้เลย raw ไม่ถูกแตะ
exit 3 = แตะเกินครึ่ง ไม่มีไฟล์ซับออกมา · exit 2 = ไฟล์ edits ผิดรูปแบบหรือขั้นก่อนหน้ายังไม่ได้รัน ข้อความบอกวิธีแก้แล้ว

### 5. ฝังซับลงวิดีโอ

**แค่ซับ** (ไม่มีภาพประกอบแทรก) ใช้ `burn` ได้ `$W/final.mp4`:

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
V="<path เต็มของคลิปที่จะฝังซับ>"
N="<ชื่อคลิปที่ใช้ตอนทำซับ ตามไฟล์ .karaoke.ass ใน $W/subs>"
"$PY" -m engine.subs burn "$V" "$W/subs/$N.karaoke.ass" -o "$W/final.mp4"
"$FF" -y -v error -ss 2 -i "$W/final.mp4" -frames:v 1 "$W/check-subs.png"
```

เปิด `$W/check-subs.png` ดูเองว่าซับอยู่ในกรอบ อ่านออก ไม่ทับหน้าคน (ปรับ `subtitle.margin_v` / `subtitle.size` ใน config แล้ว `finalize` + `burn` ใหม่)
คำสั่ง `burn` ใช้ฟอนต์ Prompt ที่มากับชุดเครื่องมือ (ไม่ต้องติดตั้งฟอนต์) และคงเสียงเดิมไว้ไม่เข้ารหัสใหม่

**ประกอบคลิปเต็มที่มีภาพแทรก** (มี `plan.json` ตาม skill tad-clip-visual ตั้ง `subs` = `subs/<ชื่อ>.karaoke.ass`) ฝังซับหลังประกอบภาพแล้วด้วย thv:

```bash
K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
W="<โฟลเดอร์งานของคลิปนี้>"
"$NODE" "$KIT/engine/visual/thv.mjs" subs "$W/plan.json"
```

ผู้ใช้ที่อยากตัดต่อต่อเองในแอปอื่น: ส่ง `.srt` ให้นำเข้า (แอปตัดต่อส่วนใหญ่อ่านแท็กคาราโอเกะ `\k` ใน `.ass` ไม่ได้ ต้องฝังด้วยคำสั่งข้างบน)

### 6. สรุปให้ผู้ใช้

บอกเป็นไทยสั้นๆ: ซับกี่บรรทัด · แก้กี่จุดและจุดสำคัญ 1-2 อัน · จุดที่สงสัยแต่ไม่ได้แก้ · path เต็มของไฟล์ที่ได้ (คลิปที่ฝังซับ + `.srt`)

## ซ่อมช่วงที่ซับหาย (ธง `ASR STALL` หรือ `GAP` ที่ระดับเสียงดัง)

ถอดเสียงบางครั้งหลุด: ท่อนพูดทั้งท่อนหายไป เหลือคำเดียวลากยาว หรือเป็นช่องว่างทั้งที่มีคนพูด วิธีซ่อม:

1. หาช่วงที่หายจากเวลาใน `review.md` ถอยจุดเริ่มไปที่รอยหายใจก่อนจุดที่หายประมาณ 1 วินาที (`--to` ใส่เมื่อรู้ว่าท่อนไหนจบ ไม่ใส่ = ถึงท้ายคลิป) จุดเริ่ม/จบควรอยู่ตรงที่เงียบ ไม่ใช่กลางคำ
2. ถอดเฉพาะช่วงนั้นใหม่แล้วเสียบกลับ:
   ```bash
   K="${CLAUDE_PLUGIN_ROOT}"; [ -f "$K/engine/env.sh" ] || K="$HOME/.tad-clip/kit"; . "$K/engine/env.sh"
   W="<โฟลเดอร์งานของคลิปนี้>"
   "$PY" -m engine.subs patch "$W/subs" --from 12.5 --to 21
   ```
   คำสั่งนี้ตัดเสียงช่วงนั้น ถอด บวกเวลาชดเชย แทนที่เฉพาะคำพูดในช่วง (คำนอกช่วงอยู่ครบ) แล้วตัดซับดิบกับ `review.md` ใหม่ · `asr.before-patch.json` เก็บต้นฉบับไว้
3. อ่าน `review.md` ใหม่ **เลข cue เปลี่ยนแล้ว** `edits.json` เดิมที่เลขไม่ตรงจะถูกตีกลับ เขียนใหม่ตามเลขชุดใหม่
4. ถอดช่วงสั้นๆ มักเว้นวรรคทุกพยางค์หรือตัดบรรทัดแปลกๆ จัดบรรทัดด้วย `resplit` ใน `edits.json`
5. ถ้ายังหาย ลองช่วงที่ยาวขึ้นหรือเริ่มก่อนหน้านี้อีก 1-2 วินาที · ถ้าเสียงไม่มีคำพูดจริง (ระดับเสียงเงียบ) ไม่ต้องซ่อม

## ปรับหน้าตาและคลังคำ

แก้ที่ `~/.tad-clip/config.json` (Windows `%USERPROFILE%\.tad-clip\config.json`) แล้วรัน `finalize` ซ้ำ:

| key | ทำอะไร | ค่าเริ่มต้น |
|---|---|---|
| `subtitle.size` | ขนาดตัวอักษร | 60 |
| `subtitle.margin_v` | ระยะจากขอบล่าง (ดันซับขึ้นพ้นปุ่มของแอป) | 340 |
| `subtitle.highlight` | สีคำที่พูดถึงแล้ว `#RRGGBB` | `#FF7F50` |
| `subtitle.max_chars` | เพดานตัวอักษรต่อบรรทัด (ต้องรันขั้น 1 ซ้ำ) | 22 |
| `brand.font` | ชื่อฟอนต์ (ต้องเป็นฟอนต์ที่อยู่ใน `assets/fonts`) | Prompt |
| `speaker.name` | ชื่อใน `[ar:]` ของ `.lrc` (ว่าง = ไม่ใส่) | ว่าง |
| `glossary` | คำของผู้ใช้เอง: `fixes` `[["ที่ถอดผิด","ที่ถูก"]]` · `glue` วลีที่ห้ามตัดข้ามบรรทัด · `protect` คำที่ให้ตรวจสะกด · `prompt_hint` คำใบ้ให้ตัวถอดเสียง | ว่าง (รวมกับคลังกลางของชุดเครื่องมือ) |

เปลี่ยน `glossary` หรือ `max_chars` แล้วรันคำสั่งขั้น 1 ซ้ำ ซับดิบจะถูกตัดใหม่เอง (ไม่ถอดเสียงซ้ำ) เลข cue อาจเปลี่ยน ตรวจ `edits.json` ใหม่

## ข้อควรรู้

- ซับตัดตามจังหวะพูด: ไม่ปล่อยคำเชื่อม (และ แล้ว ที่ จะ ...) ค้างท้ายบรรทัดเมื่อผู้พูดไม่ได้หยุด และบรรทัดถัดไปยังมีที่ว่าง · คำถูกดึงเวลาขึ้นหน้า 0.16 วินาทีเพราะตัวถอดเสียงจับจุดเริ่มคำช้ากว่าเสียงจริง
- ซับทำจากคลิปที่ตัดแล้ว (เช่น `roughcut.mp4`) เวลาจึงตรงกับคลิปนั้น ถ้าคลิปสุดท้ายยาวไม่เท่าคลิปที่ถอด (มีท่อนแทรก/ถูกตัดเพิ่ม) อย่าเลื่อนเวลาเอง ให้รันขั้น 1 ใหม่กับคลิปสุดท้ายโดยใช้โฟลเดอร์ `-o` ใหม่
- ฝังซับต้องใช้ ffmpeg ที่มี libass · ถ้าไม่มี คำสั่ง `burn` จะบอกเอง ให้ผู้ใช้พิมพ์ "ตรวจเครื่อง tad-clip"
- คลิปที่ฝังตัวอักษร hook ไว้ช่วงเปิดแล้ว: `drop` cue ที่พูดประโยคเดียวกันทิ้ง ไม่งั้นซับซ้อนกับตัวอักษร
- ไม่ต้องส่งเสียงหรือข้อความของผู้ใช้ไปที่ไหน การถอดเสียงทำในเครื่องทั้งหมด
