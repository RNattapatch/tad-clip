# ตัดคลิปพูดหน้ากล้องด้วย Claude

**ตัดคลิป (tad-clip)** by [@pun_nattapatch](https://punnattapatch.com/free/tad-clip?utm_source=github&utm_medium=readme&utm_campaign=tad-clip) · ใช้ฟรี

ถ่ายเสร็จแล้ว คลิปยังค้างเพราะไม่มีเวลาตัด?

ถ้าติดตรงต้องมานั่งไล่ช่วงพูดผิด ช่วงเงียบ แล้วทำซับอีก ลากไฟล์เข้า Claude ในแท็บ Code แล้วพิมพ์ `ตัดคลิป` ได้เลยครับ Claude จะตัดเทค ทำซับไทย ใส่ภาพประกอบตามที่คุณเลือก แล้วส่ง `final.mp4` มาให้ตรวจ

ตัดท่อนที่คุณชอบออกไป? บอก `เอาท่อนนี้คืน` ได้

![คลิปดิบเทียบกับคลิปที่ตัดด้วย tad-clip](docs/images/before-after.gif)

ผมเอาระบบที่ใช้ตัด Reel ของตัวเองมาทำเป็นชุดให้คนอื่นใช้ได้ด้วย บน Mac หรือ Windows ก็ได้ครับ คุณต้องมี Claude แพ็กเกจ Pro ขึ้นไป ส่วนโปรแกรมตัดคลิปใช้ของฟรีที่ทำงานบนเครื่อง ไม่มีค่า API เพิ่ม ถ้าให้ Claude หาภาพหรือคลิปจากเว็บ ก็ต้องต่อเน็ตและดูสิทธิ์ของไฟล์ที่หยิบมาใช้

## คลิปหนึ่งไฟล์ ทำอะไรได้บ้าง

- ตัดช่วงพูดผิด พูดซ้ำ และช่วงเงียบ พร้อมรายการว่าตัดท่อนไหน เพราะอะไร ถ้าไม่เห็นด้วย สั่งเอากลับได้
- ทำซับไทยแบบคาราโอเกะ ไฮไลต์ตามคำพูด Claude ตรวจคำที่ถอดผิดชัดเจนก่อนฝังซับ
- ใส่ภาพ คลิป การ์ดข้อความ กราฟ และเสียงเอฟเฟกต์ในช่วงที่เกี่ยวกับเรื่องที่พูด ถ้าอยากใช้มีมจากเน็ต Claude จะถามเรื่องไฟล์และสิทธิ์ก่อน
- วางผู้พูดคู่กับภาพแบบแบ่งจอ หรือตัดพื้นหลังคนพูดออกได้ บน Mac ใช้ Apple Vision; บน Windows ต้องติดตั้งตัวเสริมสำหรับตัดพื้นหลัง
- ส่งออกแนวตั้งค่าเริ่มต้นที่ 1080 × 1920 พิกเซล ไม่เกิน 30 fps หรือเลือก 2K 60 fps ได้ ถ้าใส่ภาพประกอบ จะมีรายการตำแหน่งภาพสำหรับคนที่อยากไปแต่งต่อใน CapCut

ก่อนลงมือตัด Claude จะถามสั้นๆ ว่าคุณตัดเทคมาเองหรือยัง เอาแค่ซับหรือใส่ภาพด้วย ใช้ไฟล์ของคุณหรือให้หาจากเว็บ แล้วจะให้ถามระหว่างทางหรือทำรวดเดียวจนจบ

[ดูตัวอย่าง storyboard ก่อนเรนเดอร์](docs/images/storyboard.png) — แต่ละช่องบอกว่าจะเห็นอะไรในช่วงไหนของคลิป

## เตรียมเครื่อง

| ต้องมี | รายละเอียด |
|---|---|
| Claude | แพ็กเกจ Pro ขึ้นไป ใช้แท็บ Code ในแอป Claude บนคอม และตั้ง Environment เป็น Local |
| เครื่อง | Mac แนะนำชิป Apple M1 ขึ้นไป หรือ Windows 10/11 แบบ 64-bit |
| RAM | อย่างน้อย 8 GB; 16 GB ทำงานสบายกว่า |
| พื้นที่ว่าง | ประมาณ 15 GB สำหรับโปรแกรม โมเดลถอดเสียง และไฟล์ระหว่างตัด |
| อินเทอร์เน็ต | ใช้ตอนติดตั้งและตอนทำงานกับ Claude |

โมเดลถอดเสียงคือ large-v3 ทุกเครื่อง แม้ RAM 8 GB (ใช้ RAM ราว 3 GB) มี medium ให้เลือกเองเป็นทางสุดท้าย แต่ฟังภาษาไทยพลาดมาก

บน Mac ต้องมี Homebrew ส่วน Windows ต้องลง [Git for Windows](https://git-scm.com/download/win) ก่อน (ฟรี เพราะ Claude ใช้ Git Bash รันคำสั่ง) คู่มือติดตั้งพาไปทีละขั้น โปรแกรมที่ชุดนี้ใช้ ได้แก่ whisper.cpp บน Mac หรือ faster-whisper บน Windows สำหรับถอดเสียง, ffmpeg สำหรับตัดวิดีโอ และ Chrome หรือ Edge แบบไม่มีหน้าต่างสำหรับทำการ์ด

## เริ่มใช้ 3 ขั้น

1. เพิ่ม plugin ในแอป Claude แท็บ Code: กด **+ → Plugins → Add plugin** แล้วใส่ `RNattapatch/tad-clip` หรือพิมพ์สองบรรทัดนี้ในช่องแชททีละบรรทัด

   ```text
   /plugin marketplace add RNattapatch/tad-clip
   /plugin install tad-clip@pun-nattapatch
   ```

2. พิมพ์ `ติดตั้ง tad-clip` Claude จะบอกว่าต้องลงอะไร ใช้พื้นที่เท่าไร และถามก่อนเริ่ม ถ้า Mac ยังไม่มี Homebrew หรือ Windows ยังไม่มี Git for Windows คู่มือจะบอกขั้นที่คุณต้องทำเอง หลังเตรียมสองโปรแกรมนี้แล้ว ขั้นติดตั้งชุดตัดคลิปใช้เวลาราว 10–30 นาทีตามความเร็วเน็ต ส่วนใหญ่เป็นเวลาโหลดโมเดลถอดเสียง

3. ลากวิดีโอเข้าแชทแล้วพิมพ์ `ตัดคลิป` จะเลือกให้ Claude ถามก่อนตัดสินใจสำคัญ หรือให้ทำต่อจนได้ไฟล์แล้วค่อยสั่งแก้ก็ได้

คู่มือติดตั้ง: [Mac](docs/01-install-mac.md) · [Windows](docs/02-install-windows.md) · [ตัดคลิปแรก](docs/03-first-clip.md)

## ใช้เวลานานเท่าไร

ผมลองกับคลิปดิบ 107 วินาทีบน Mac ชิป M4 ให้ Claude ตัดเทค ทำซับ หาภาพจากเว็บ วางภาพ แล้วเรนเดอร์จนจบ ใช้ 30 นาที ได้คลิป 72 วินาที ตัดออก 19 ท่อน

นี่เป็นผลจากคลิปเดียวบนเครื่องผม ถ้าคุณเลือกแค่ตัดกับทำซับ งานจะน้อยลง ส่วน Windows ที่ไม่มีการ์ดจอ NVIDIA ขั้นถอดเสียงอาจนานกว่า Mac มาก
