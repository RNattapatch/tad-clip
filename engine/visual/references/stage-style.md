# Stage style — ผู้พูดยืนบนเวทีเดียว โลกด้านหลังเปลี่ยน (`plan.mode: "stage"`)

> อ่านเมื่อผู้ใช้เลือก mode `stage` · ไวยากรณ์ทั่วไป (layout · overlay · จังหวะพื้นฐาน) ยังอยู่ใน `visual-modes.md`
> ตัวอย่างเต็ม: `../examples/stage-demo.plan.json` (10 ช็อต · 16 วิ · ภาพกราฟิกวาดด้วยโค้ด + เงาคนตัวแทน)

**หลักเดียว:** ผู้พูดยืนตำแหน่งเดิมบน "พื้นเวที" แผ่นเดียวกันทุกฉาก ฉากหลังเปลี่ยนตามทุกคำนามที่พูด · ตาคนดูไม่ต้องหาคนพูดใหม่ แม้ภาพเปลี่ยนทุก 1–2 วิ

ต่างจาก `cutaway` (ค่าเริ่มต้น): cutaway ตัด*ออกไป*หาภาพแล้ว*กลับมา*ที่ผู้พูด · stage ไม่ตัดออก ผู้พูดอยู่ในภาพเกือบตลอด แต่โลกรอบตัวเปลี่ยน

---

## 1. จังหวะ (ตัวตรวจ `thv check` เตือนให้)

| ค่า | เป้า | ตัวตรวจ |
|---|---|---|
| ภาพค้างช่วงเปิด (12 วิแรก) | ≤ 2 วิ | เตือนเมื่อเกิน |
| เฉลี่ยทั้งคลิป | ≤ 2.5 วิต่อภาพ (นับภาพ carousel ทีละใบ) | เตือนเมื่อเกิน |
| ตัวเลขใหญ่บนจอ | ทุก 10–15 วิ ถ้าเรื่องมีตัวเลขจริง | — (ห้ามแต่งตัวเลขเพื่อให้ถึงเป้า) |
| ซอยประโยค | ประโยคเดียวที่มี 2 คำนาม = 2 ฉาก | — |
| พื้นเวที | มี `plan.stage_floor` | เตือนเมื่อไม่มี |

## 2. ช็อต 4 แบบ (ผสมกัน · แบบเดียวกันไม่เกิน 3 ช็อตติด)

| แบบ | layout + ฟิลด์ | ใช้เมื่อ | สัดส่วนโดยประมาณ |
|---|---|---|---|
| **เวที** ผู้พูดตัวจริงบนฉาก | `cutout` + `visual.image` (ฉากหลัง) | ทุกครั้งที่พูดถึงสถานที่/สถานการณ์ | ~40% |
| **เวที + รูปนิ่ง** | `cutout` + `visual.image` + `visual.pose` | จังหวะอารมณ์เปลี่ยน (ตกใจ · ชี้ · หัวเราะ) สั้น 1–1.5 วิ | 2–4 ช็อตต่อคลิป |
| **การ์ดกระดาษกราฟ** | `full-card` + `card.type: "grid"` | แนะนำตัวละคร/สิ่งของ · ไล่ทีละอย่าง (carousel) · ตัวเลขใหญ่ · คำถาม | ~30% |
| **แบ่งจอ** | `split` + `visual.image` / `footage` | ต้องเห็นภาพกับหน้าผู้พูดพร้อมกัน · เปิดคลิป · มีม | ~25% |

ปิดท้ายด้วย `full-speaker` เปล่าได้ (CTA ที่ต้องเห็นหน้า) · ใส่ `"whip": false` ให้ตัดตรงเข้าช็อตนั้น

## 3. ฟิลด์ของ mode stage

| ฟิลด์ | ใส่อะไร | หมายเหตุ |
|---|---|---|
| `plan.mode` | `"stage"` | ตั้ง look ของ stage ให้เอง · ไม่ใส่ = `cutaway` |
| `plan.stage_floor` | path ภาพพื้น 1 ภาพ (เทียบโฟลเดอร์ plan) | วางทับฉาก `cutout` ทุกฉากตั้งแต่ y 1300 ลงมา ขอบบนจาง 140 px · ฉากหลังขยับช้า พื้นนิ่ง = มีมิติ · ภาพพื้นที่ดี: คอนกรีต ไม้ ยางมะตอย สีกลางๆ ไม่มีลาย |
| `plan.floor_top` · `visual.floor_top` | px (1080×1920) | เลื่อนขอบบนของพื้นทั้งคลิป / เฉพาะช็อต |
| `visual.stage: false` | — | ปิดพื้นเวทีเฉพาะช็อต (ฉากที่พื้นในภาพสวยอยู่แล้ว) |
| `visual.image` | path ภาพ png/jpg/webp | ภาพเต็มช่องภาพของ layout นั้น (ใช้ได้ทุก layout ไม่ใช่แค่ stage) |
| `visual.pose` | `{ file, h, y, x? }` | รูปนิ่งพื้นใสของผู้พูด ยืนแทนคลิปสด · `h` ความสูง px · `y` ขอบบน px · `x` จุดกึ่งกลางแนวนอน % (ค่าเริ่ม 50) · compose ไม่วางตัวสดในช็อตนี้ (เสียงพูดเดินต่อ) · ใช้ได้แม้เครื่องไม่มีตัวตัดพื้น |
| `plan.whip` | `{ dur: 0.12, sigma: 60 }` (mode stage เปิดให้เองด้วยค่านี้) | เบลอแนวนอนคร่อมทุกรอยต่อตอน compose · `shot.whip: false` = ตัดตรงเข้าช็อตนั้น · `plan.whip: false` = ตัดตรงทั้งคลิป · ใช้กับ mode cutaway ได้ด้วย |
| `plan.cutout.scale` | ค่าเริ่มใน stage 0.72 | ขนาดผู้พูดตัวจริงบนเวที |
| `plan.cutout.fade_side` | 0–0.5 (เช่น 0.08) | จางขอบซ้าย/ขวาของตัวที่ตัดพื้น — คลิปครึ่งตัวมีเส้นตรงตรงขอบเฟรมเดิม |
| shot `sub_y` | ค่าเริ่มใน stage 44 สำหรับช็อต `cutout` | ซับลอยเหนือหัว เพราะผู้พูดยืนล่างแล้วแถบซับปกติทับหน้า · `plan.stage_sub_y` เปลี่ยนค่าเริ่มทั้งคลิป |

**การ์ด `grid`** (`visual.card`)

| ฟิลด์ | ภาพ |
|---|---|
| `theme: light \| dark` | กระดาษกราฟสีอ่อน (โทน `paper`) / เข้ม (โทน `primary-deep`) มีรอยยับจางๆ |
| `images[]` | 1 ภาพ = การ์ดมุมมนเด้งเข้า · 2 ภาพขึ้นไป = carousel ปัดซ้ายทีละใบ + เบลอแนวนอนตอนเลื่อน |
| `at[]` | วินาที (นับจากต้นช็อต) ที่ปัดไปภาพถัดไป ภาพละ 1 ค่ายกเว้นภาพแรก · ไม่ใส่ = ทุก 0.9 วิ |
| `badge { big, small?, at? }` | วงกลมเด้งที่มุมขวาล่างของการ์ด (ไม่ทับหน้าคนในภาพ) · ข้อความ 1–3 คำ |
| `lines[]` + `accent` | ข้อความใต้ภาพ บรรทัดที่ `accent` เป็นกล่องสีเน้น |
| `big` + `caption` | ตัวเลขใหญ่ + คำอธิบาย · **ต้องมี `source`** (ไม่มี = เตือน) |
| `source` | ที่มา ใต้การ์ด · ภาพจำลองขึ้นต้น `ภาพจำลอง ·` |

## 4. ภาพมาจากไหน (ฟรีทั้งหมด เรียงตามลำดับ)

1. **รูปของผู้ใช้เอง** — รูปทำงานจริง ร้าน ทีม สินค้า = ดีที่สุด (เป็นหลักฐานด้วย)
2. **stock ฟรี** ผ่าน skill tad-clip-library (Pexels · Pixabay · Wikimedia Commons + เครดิตใน `CREDITS.md`) · ฉากหลังหาแนวตั้ง หรือแนวนอนที่ครอปกลางได้
3. **บล็อก prompt** `thv prompts` → ผู้ใช้เอาไปวางในเครื่องมือทำภาพที่ใช้อยู่เอง (ตัวฟรีก็ได้) · บอกในฉากว่า 1/3 ล่างเรียบ (พื้นเวทีจะทับ) · `plan.style: "photo"`
- ภาพ AI และ stock ที่ยืนแทนเหตุการณ์จริง → ป้าย `ภาพจำลอง · …` ทุกช็อต (overlay `source` หรือ `source` ของการ์ด)
- ภาพทั้งคลิปเป็นภาพถ่ายสมจริงโทนเดียวกัน · อย่าปนภาพวาดกับภาพถ่าย

## 5. รูปนิ่งของผู้พูด (pose)

- ถ่ายเตรียมไว้ 2–4 ท่า ใช้ซ้ำได้ทุกคลิป: ยืนตรงยิ้ม · ชี้ขึ้น · ตกใจ/มือกุมหัว · ถือของ · เต็มตัวหรือครึ่งตัว พื้นหลังเรียบ แสงเดียวกับที่ถ่ายคลิป เสื้อชุดเดียวกับในคลิป
- ตัดพื้น: `"$PY" -m engine.cutout "<รูป.jpg>" "<ท่า.png>"` → PNG พื้นใส ครอปพอดีตัว (Mac ใช้ Apple Vision · Windows ใช้ transparent-background ที่ติดตั้งด้วย `--with-cutout`)
- ปากไม่ขยับ → ใช้สั้น 1–1.5 วิ ในจังหวะที่ประโยคสั้นหรือเว้นหายใจ
- ตั้ง `h` / `y` ให้หัวอยู่ระดับเดียวกับตัวสดในช็อตข้างๆ (ดูใน storyboard) ไม่งั้นคนดูเห็นว่าตัวกระโดด

## 6. ข้อจำกัดที่ต้องบอกผู้ใช้

- **คลิปครึ่งตัว** (ถ่ายใกล้ ถือไมค์) ตัดพื้นแล้วดูเหมือนยืนหลังเคาน์เตอร์ ไม่ใช่ยืนเต็มตัวบนเวที · อยากได้เต็มตัว ต้องถ่ายใหม่ ห่างกล้อง ~3 ม. เห็นถึงเท้า
- ฉากที่พื้นในภาพเป็นพื้นขัดเงาอยู่แล้ว พื้นเวทีจะกลืนไปกับฉาก (ไม่เสียหาย แต่ไม่เห็นเป็นแถบเวที)
- ซับย้าย 3 ระดับ (เหนือหัวในช็อตเวที · ใต้รอยต่อใน split · ตำแหน่งปกติบนการ์ด) — ปกติของ mode นี้
- เรื่องที่ไม่มีของจริงให้โชว์ ภาพส่วนใหญ่จะเป็นภาพจำลอง → บอกผู้ใช้ตรงๆ และติดป้ายครบ

## 7. Checklist ก่อนส่ง storyboard

1. `thv check` ไม่มี ❌ · เฉลี่ย ≤2.5 วิต่อภาพ
2. ผู้พูด (ตัวสดและ pose) ยืนระดับเดียวกันทุกฉาก · หัวไม่ชนป้ายที่มา
3. การ์ด `grid` ตัวหนังสือไทยไม่ตัดกลางคำ · badge ไม่ทับหน้าคนในภาพ
4. ตัวเลขทุกตัวมีที่มา · ภาพจำลองมีป้ายครบ
5. ช็อตสุดท้าย (หรือ CTA) `whip: false`
