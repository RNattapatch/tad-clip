# Visual modes — ไวยากรณ์ภาพของคลิปพูดหน้ากล้อง

> อ่านทุกครั้งก่อนเขียน `plan.json` · look `vox` (explainer แบบ Vox · โครง 7 beat · การ์ดเอกสาร/กราฟ/timeline · การ์ดอก) → อ่าน `vox-style.md` เพิ่ม · mode `stage` → อ่าน `stage-style.md` เพิ่ม
> ตัวอย่างเต็ม: `../examples/lead-leak.plan.json` (12 ช็อต · 39 วิ · look ปกติ) · `../examples/vox-star-sales-leaves.plan.json` (9 ช็อต · 37 วิ · look vox) · `../examples/stage-demo.plan.json` (10 ช็อต · 16 วิ · mode stage)

**หลักเดียว:** ผู้พูดเป็นหมุด (คนเดิม มุมเดิม เสียงต่อเนื่อง ซับตำแหน่งเดิม) · **โลกด้านหลังเปลี่ยนตามสิ่งที่กำลังอธิบาย**

## 0. Mode 2 แบบ (ค่า `mode` ใน plan.json · ไม่ใส่ = `cutaway`)

| mode | หน้าตา | layout ที่ใช้มาก | จังหวะ | อ่านเพิ่ม |
|---|---|---|---|---|
| `cutaway` (ค่าเริ่มต้น) | ผู้พูดพูดหน้ากล้อง ตัดไปของจริง/คลิปจริง/stock/มีม/การ์ด แล้วกลับมาที่ผู้พูด · look ปกติหรือ `vox` | `split` · `full-card` · `full-speaker` · `proof` | ภาพค้างช่วงเปิด ≤3 วิ (vox 4) | §1–4 ไฟล์นี้ · `vox-style.md` ถ้า look vox |
| `stage` | ผู้พูดตัดพื้นยืนบนพื้นเวทีแผ่นเดียวกันทุกฉาก ฉากหลังภาพสมจริงเปลี่ยนทุก 1–2 วิ + การ์ดภาพบนกระดาษกราฟ + ตัวเลขใหญ่ + เบลอทุกรอยต่อ + สลับรูปนิ่งของผู้พูดในจังหวะอารมณ์เปลี่ยน | `cutout` · `full-card` (grid) · `split` | ภาพค้างช่วงเปิด ≤2 วิ · เฉลี่ย ≤2.5 วิต่อภาพ | `stage-style.md` |

- `mode: "overlay-on-cut"` (ทับคลิปที่ตัดเสร็จแล้ว) ยังใช้ได้เหมือนเดิม
- plan ที่เขียนก่อนมี mode (ไม่มีค่า `mode`) = `cutaway` ทำงานเหมือนเดิมทุกอย่าง
- `stage` ต้องตัดพื้นหลังผู้พูดได้ (Mac = vision · Windows = tb) **หรือ** ใช้รูปนิ่งที่ตัดพื้นแล้ว (`visual.pose`) ทุกช็อตเวที

## 1. Layout 5 แบบ (ค่า `layout` ใน plan.json)

| layout | จอ 1080×1920 | ผู้พูดอยู่ไหน | ใช้เมื่อ | ต้องมี |
|---|---|---|---|---|
| `split` | บน 0–960 = ภาพ · ล่าง 960–1920 = ผู้พูด | ครึ่งล่าง (ถ่ายปกติ ไม่ต้องตัดพื้น) | **Hook 0–3 วิ** · ช็อตที่ต้องเห็นหลักฐานกับหน้าผู้พูดพร้อมกัน · มีม · **ฟองแชต** (`visual.panel: primary\|paper` = พื้นเรียบครึ่งบน) | `visual.proof_file` / `footage` / `ai` / `card` / `panel` |
| `cutout` | ภาพเต็มจอ + ผู้พูดตัดพื้นยืนล่างกลาง ~62% (mode stage 72%) | ล่าง 25–40% | ยิงตัวอย่างรัว (evidence stack) · ฉากสะสมเหตุ→ผล · ช็อตเวทีของ mode stage | `visual.image` / `proof_file` / `ai` + เครื่องที่มีตัวตัดพื้น (Mac = vision · Windows = tb ถ้าติดตั้ง) หรือ `visual.pose` |
| `full-card` | การ์ดเต็มจอ (ผู้พูดหายจากภาพ เสียงเดินต่อ) | — หรือหน้าลอยบนการ์ดถ้าเปิด `face_circle` | รีเซ็ตสายตา · ประกาศ "มี N ข้อ" · ผังกลไก · CTA | `visual.card` |
| `full-speaker` | ผู้พูดเต็มจอ | ทั้งจอ | พักสายตาสั้นๆ · ประโยคที่ต้องเห็นหน้า/อารมณ์ · การ์ดอก (look vox) | overlays (ไม่บังคับ) |
| `proof` | ของจริงเต็มจอ (ภาพหน้าจอระบบ · แชต · ใบเสนอราคา · รูปหน้างาน · คลิปจริง) | — | ปิดท้ายด้วยหลักฐาน · **ห้ามใช้ภาพ AI แทน** | `visual.proof` (+ `proof_file` หรือ `footage`) |

> plan รุ่นก่อน kit (layout ชื่อเดิมของ `full-speaker` · สี `navy/coral/gold`) ยังอ่านได้ — thv แปลงเป็น `full-speaker` / `primary/accent/accent2` ให้เอง
> เครื่องที่ไม่มีตัวตัดพื้น (`cutout.engine` = off) → `thv check` ไม่ยอมให้ใช้ `cutout` → ใช้ `split` แทน

## 2. การ์ด (สร้างในเครื่อง · ตัวหนังสือไทยเป๊ะ · ฟรี · สีจากแบรนด์ใน config)

สีแบรนด์ 4 ช่อง: `primary` (พื้นเข้ม/หมึก) · `paper` (พื้นกระดาษ) · `accent` (สีเน้น 1 สีต่อจอ) · `accent2` (ตัวเลข/สีเน้นรอง) — ค่าจริงมาจาก preset ที่ผู้ใช้เลือกตอน setup

**เต็มจอ (`visual.card.type`)**
| type | ฟิลด์ | ภาพ |
|---|---|---|
| `title` | `lines[]` · `accent` (index บรรทัดเน้น) · `theme: primary\|paper\|accent` | คำกระแทกทีละบรรทัด บรรทัดเน้น = กล่องสีเน้น |
| `flow` | `nodes[]` · `leaks[]` (index ลูกศรที่รั่ว) · `leakText` · `hot[]` · `reveal` · `heading` · `step` | ผังแนวตั้งโผล่ทีละกล่อง = **ฉากสะสมเหตุ→ผลโดยไม่ต้องใช้ภาพ AI** |
| `compare` | `left{title,items[]}` · `right{title,items[]}` · `heading` | สองคอลัมน์ ✕ / ✓ โผล่ทีละแถว |
| `stat` | `value` · `caption` · `source` | ตัวเลขใหญ่ — **ตัวเลขจริงเท่านั้น** ห้ามแต่ง |
| `cta` | `big[]` · `small` | ตัวใหญ่ + บรรทัดเล็ก |
| `doc` `chart` `timeline` `quote` `chapter` | ดู `vox-style.md` §3 | ใช้ได้ทั้งสอง look |
| `grid` | `theme: light\|dark` · `images[]` · `at[]` · `badge{big,small,at}` · `lines[]` + `accent` · `big` + `caption` · `source` | การ์ดภาพมุมมนบนกระดาษกราฟ · หลายภาพ = carousel ปัดซ้าย · ตัวเลขต้องมี `source` — รายละเอียด `stage-style.md` §3 (ใช้ได้ทุก mode) |

**ซ้อนบนภาพ (`overlays[]`)** — ตำแหน่งเป็น % ของเฟรม
| type | ฟิลด์ | หน้าที่ (ห้ามสลับ) |
|---|---|---|
| `hook-pill` | `text` (`*คำ*` = สีเน้น) · `y` | ประโยคที่บอกว่าคนดูจะได้อะไร — วางตรงรอยต่อ split (`y` 45–50) |
| `label` | `text` · `x` `y` · `color: accent\|primary\|accent2` | ป้ายสั้น 1 ชิ้นต่อภาพ (ชื่อช่องทาง · ชื่อจุดรั่ว) ≤4 คำ |
| `counter` | `n` · `of` | ตัวนับ `1/3` มุมขวาบน |
| `chat` | `messages[{side: me\|them, text}]` · `y` (ไม่ใส่ = กลางครึ่งบน) · `step` | ฟองแชต: อีกฝ่าย = เทาชิดซ้าย · ฝั่งเรา = สีเน้นชิดขวา · เด้งทีละฟอง — ประโยคที่คนดูจะก๊อปไปใช้ |
| `image` | `file` (เทียบโฟลเดอร์ plan) · `w` · `x` `y` · `pop` · `delay` | PNG ใส: โลโก้ · สติกเกอร์มีมบนการ์ด |
| `source` | `text` · `y` (ขอบบนของป้าย · ค่าเริ่ม 14) | ป้ายที่มาเล็กมุมซ้ายบนภาพจริง/คลิป/มีม · ภาพจำลอง (AI **และสต็อกที่ยืนแทนเหตุการณ์จริง**) ขึ้นต้น `ภาพจำลอง ·` · `visual.footage.source` วาดเป็นป้ายเดียวกันให้เอง |
| `highlight` | `x` `y` = **จุดกึ่งกลาง**ของแถบ · `w` `h` · `color: accent2` · `delay` | แถบไฮไลต์บนตัวหนังสือในภาพจริง · ต้องมี `visual.proof_file` · `h` = ความสูง 1 บรรทัดในภาพ |
| `annotate` | `shape: circle\|underline\|box\|arrow` · `x` `y` = **จุดกึ่งกลาง** · `w` `h` · arrow ใช้ `from [x,y]` `to [x,y]` | เส้นวาดมือ 1 ชิ้นต่อช็อต |
| `keyword` | `lines[]` (≤3) · `y` = กึ่งกลาง (56) | การ์ดอก — กล่องสีเน้นต่อบรรทัด · ไม่ทับหน้า |
| `name` · `docchip` | `name` `role` `y` (ขอบบน 52) · `text` `meta` `y` (กึ่งกลาง 56) | ป้ายชื่อ · เอกสารแผ่นเล็ก (รายละเอียดใน `vox-style.md` §3) |

**ภาพจากไฟล์ `visual.image`** (ทุก layout · ทุก mode): path ภาพ png/jpg/webp เทียบโฟลเดอร์ plan → เต็มช่องภาพของ layout (ครึ่งบนของ split · ทั้งจอของ cutout/proof) · ไม่ต้องย้ายเข้า `assets/ai` หรือ `assets/proof` · หาไฟล์ไม่เจอ = error
**การจัดภาพ `visual.treat`** (ทุก look · ใช้กับ `proof_file` หรือภาพ AI): `print` = รูปพิมพ์ขอบขาวเอียงวางบนกระดาษ · `duotone` = ขาวดำย้อมสี `primary`/`paper`
**พิกัด:** ทุกค่าเป็น % ของเฟรม 1080×1920 · ชิ้นที่วางกลาง (`hook-pill` `label` `keyword` `docchip` `highlight` `annotate` `image`) ใช้ `x`,`y` เป็นจุดกึ่งกลาง · `source` `name` `chat` ใช้ `y` เป็นขอบบน

ซับของเสียงพูด = ไฟล์ `.karaoke.ass` (ทำโดย tad-clip-subs) burn ด้วย `thv subs` · **ไม่อยู่ในการ์ด**

## 3. จังหวะ (ตัวตรวจ `thv check` เตือนให้)

1. **12 วิแรก ภาพค้างไม่เกิน 3 วิ** (look vox 4 วิ) — ช่วงยิงตัวอย่างเปลี่ยนภาพทุก 1.5–2 วิ
2. **การ์ดเต็มจอ/split รีเซ็ตสายตาทุก 12–18 วิ**
3. **ข้อความซ้อนไม่เกิน 2 ชั้นต่อช็อต** (ไม่นับตัวนับ) — จอโทรศัพท์อ่านไม่ทัน
4. **ผู้พูดเต็มจอเปล่าได้ ~6 วิ** แล้วต้องเติม label หรือเปลี่ยนภาพ
5. **ช็อตแรกต้อง split หรือมี hook-pill** — 2 วิแรกเห็นหลักฐาน + รู้ว่าจะได้อะไร
6. **ต้องมีช็อตของจริงอย่างน้อย 1** (`proof` หรือ `footage`) — กราฟิกอธิบาย ของจริงปิด · หัวข้อที่ไม่มีของจริงให้โชว์ (ความสัมพันธ์/มุมคิด) ใส่ `"proof_exempt": "เหตุผล"`
7. **1 คลิป 1 ภาษาภาพ** (`plan.style` เดียว ถ้ามีภาพ AI) — ภาพหลายสไตล์ปนกันดูไม่เป็นชุด
8. **ห้ามวางฟองแชต/ข้อความยาวบน `full-speaker`** — หน้าผู้พูดกินพื้นที่ราว 20–60% ของจอ · ใช้ `split` + `panel` แทน (label สั้นเหนือหัวได้)

## 4. เลือกภาพให้ตรงชนิดข้อมูล

ลำดับความสำคัญของวัตถุดิบ: **ของจริงเป็นกระดูก → การ์ดเป็นจังหวะ → มีมเป็นเครื่องปรุง** · ภาพ AI ใช้เฉพาะฉากที่ไม่มีของจริง (ไม่บังคับ · ทำเองนอก kit)

| บีตในบท | ใช้ | เหตุผล |
|---|---|---|
| เปิดคลิป (hook) | `split` + ภาพ/คลิปจริง + `hook-pill` | เห็นหลักฐาน + เห็นหน้าคนพูดใน 2 วิ |
| สถานที่/อาการธุรกิจ ("ลีดกองเต็มโต๊ะ") | `split`/`cutout` + ภาพจริง (หรือภาพ AI ถ้าไม่มีจริง) | ต้องเห็นเป็นฉาก |
| ยิงตัวอย่าง 3–4 อัน | `cutout` (หรือ `split`) ต่อกัน ช็อตละ 1.5–2 วิ + `label` | mini-payoff ทุกช็อต |
| เหตุ→ผลหลายขั้น | การ์ด `flow` / `timeline` (หรือภาพชุด "แก้ภาพเดิม" `edit_of`) | โลกเดิมที่ "โตขึ้น" ไม่ใช่สุ่มภาพใหม่ทุกประโยค |
| ระบบ A vs B | `compare` | ผังเดียวเห็นความต่าง |
| ประกาศ "มี N ข้อ" | `title` แล้วตามด้วย `counter` | รีเซ็ต + บอกความยาว |
| ตัวเลข | `stat` / `chart` + `source` | ตัวเลขต้องมีที่มาบนจอ |
| เรื่องคน/แบรนด์จริง | ภาพจากหน้าทางการ · คลิปโฆษณาจริง · ฟุตเทจยุค (`footage`) | ดูสูตรใน SKILL.md "ของจริง + มีม" |
| ประโยคตบมุก | มีม `split` 1.5–2.5 วิ (ภาพอย่างเดียว) | ~3 ตัวต่อ 60 วิ ตรงประโยคที่ขำจริง ไม่ใช่คั่นเวลา |
| หลักฐาน | `proof` | ความน่าเชื่อถือหลังช่วงกราฟิก |
| ปิด | `cta` (save/share หรือ action เดียวที่ทำได้พรุ่งนี้) | action เดียว |
